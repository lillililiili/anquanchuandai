# 巡检工人端页面设计核验

## 独立交付
- 新版目录：华能巡检工人端页面设计；端口 18771。
- 原版目录与端口 18770 保留；原版全部 site 文件逐字节对比此前 ZIP，确认一致。

## 验证结果
- 26 个工人业务页在 408×900 逻辑视口逐页渲染及滚动，无布局异常。
- 3 项自动测试通过：巡检完成条件、全页渲染、视频来电接听/切换/挂断返回。
- 最终静态分析无问题，Release Web 构建成功。
- 浏览器已检查登录、厂站、工作台、通讯、视频通话、固定挂断、返回结束确认、协作人员、位置、九点轨迹播放及设备详情。
- 工作台、通讯、视频、协作人员、位置、轨迹、设备详情截图见页面核验目录。轨迹截图为默认选中视觉修正前，最终代码已设今日默认选中并提高图上标签对比度；这两处小修通过静态与布局测试。

## 样式对照
- 基线为原蓝色 ROLLING 原型；使用同一项目的主题、组件、素材与图标。
- 对照保留 Logo、浅蓝页面底色、白卡、蓝色按钮、设备图片与四栏导航；内容层次按工人角色调整，非逐像素复刻。
- 两轮浏览器视觉检查：首轮发现通话挂断需要滚动、示意标签对比度不足；修正为固定挂断与白底标签后复核视频页。
- 图标采用原 Material Icons；未以 emoji、文字方块代替操作图标。地图线路为功能绘制，不替代图标。

## 边界
- 未进行 Android 真机、真实音视频、定位、扫码、上传及华能接口联调。
- 绑定和硬件检查是设计状态；地图和视频均明确示意。
- 登录及厂站页保留原版；新版仍共用源码组件，通过 WORKER_PREVIEW 编译标志隔离。

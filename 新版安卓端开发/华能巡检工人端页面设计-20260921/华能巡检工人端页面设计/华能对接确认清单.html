建议架构

独立安卓 APP ↔ 智能穿戴业务后台 ↔ 华能大系统。

设备、通讯服务接入业务后台或专用服务；厂商 SDK、视频路由及网络部署由联调确定。

APP 不保存华能系统服务端密钥。人员权限、鉴权协议、访问网络与部署位置需双方确认。

失败与重复处理建议

- APP 离线时保存草稿；正式提交须取得后台持久化确认，不能把本机保存显示成已送达。

- 后台回传以固定核验 ID 去重；网络失败重试同一记录，业务拒收需展示原因并按约定修正。

- HTTP 成功不等于业务接收成功；显示业务回执后才进入“对方已接收”。

- 来源不可用时标记“同步失败 / 数据可能过期”，保留最后同步时间；不得显示虚构的最新状态。

- 账号过期、无权限、附件上传失败要保留可恢复输入，重新授权后才能继续提交。

评审演示顺序

1. 打开安卓演示 → 使用虚构内容填写登录 → 选择演示厂站 → 进入现场。

2. 查看现场作业、人员与装备；进入作业详情及相关子页。

3. 通讯、消息、我的分别查看现有页面与操作流程；核验、SOS与通讯仅为演示。

4. 对照本表确认数据来源、回传内容与责任边界。

5. 关闭后重新打开或点击桌面“重新体验登录”可重新演示。

本版保持现有安卓页面，不新增“数据同步与回传”手机页面。待回传、失败重试、接收回执是本文提出的对接状态建议，尚未纳入这版原型交互。附件与缺少数据的功能以实际页面演示能力为限。

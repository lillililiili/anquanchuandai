# 管理员主页模块重构 · 2026-09-21

已完成。修改范围为本目录的网页模拟项目。

## 页面与功能

- 移除顶部悬浮的管理员告警胶囊，在原生 Flutter 工作台中增加「现场管理」卡片，包含「全局态势」「作业研判」两项入口。保留原有 Logo、厂站头图、任务、设备、巡检工具及底部导航。
- 全局态势：在岗/作业/围栏告警/在线率概览、厂区示意图、人员选择、装备状态、模拟语音和视频联系、围栏告警及现场通讯录。
- 作业研判：状态与类型筛选、人员/事件搜索、详情、认领、处置意见、示例凭证、转交、复核关闭、重新开启、处置记录。
- 两个模块共用事件状态，认领和关闭后同步更新主页与态势页数量。数据保存在当前浏览器标签页的 sessionStorage，刷新保留；「重置演示」恢复初始五条事件。
- 登录页、厂站选择页及巡检员身份不显示管理员入口；切换巡检员时关闭已打开的管理页面。全局打开方法与操作处理均校验模拟身份。
- 桌面左侧身份切换可进入模拟登录并选择厂站；已进入工作台后可即时切换身份。原有登录表单继续保留。
- 修复原先「异常上报」误用研判回调的问题，恢复原有上报页。

- 管理员切换巡检员后，主页管理卡片、侧栏入口、SOS 内研判入口隐藏，管理子页关闭。
- 浏览器未记录 JavaScript error；检查的管理面板宽度与滚动宽度一致，未发现横向溢出。

## 维护说明

新模块位于 `site/admin.js` 和 `site/admin.css`；`site/index.html` 负责加载、身份导览及快捷切换，`site/main.dart.js` 接入原生主页卡片和回调。本交付目录只有编译后的 Flutter Web 文件，没有 Dart 源码，因此接入改动位于现有编译产物中；未来重新构建 Flutter 时需要将主页入口移入对应 Dart 源码。

旧 `events.js`、`field_lead.js` 不再加载。保留 `events.css` 是因为原 SOS 页面复用了其中的公共样式。

本次新模块的地图、定位、通信和处置均明确标为模拟，没有调用真实通信或告警后端。角色限制是模拟项目的前端演示行为。

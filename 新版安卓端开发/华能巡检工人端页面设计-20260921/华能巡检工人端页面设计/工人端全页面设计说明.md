# ROLLING 巡检工人端 · 全页面设计

本版按用户确认的角色调整：戴安全帽的一线巡检工人。核心是语音通话、视频通话，保留协作人员位置、协作人员轨迹、本人设备信息与状态。全部运行数据为本地示例，未连接华能系统。

## 视觉与修改原则

- 沿用既有 ROLLING Logo、蓝色主色、浅蓝底色、白色圆角卡片、原有插画、按钮比例及四栏底部导航。
- 复用原项目 WearBrandHero、WearCard、WearAssetImage、WearBadge 等组件和 WearArt 素材。未生成或引入新图片。
- 保留原登录、密码重置、厂站选择页面。工作台、通讯、消息、我的改为工人使用内容。
- 删除可见的管理入口：作业监护、任务分配、任务成员管理、全员设备查询、围栏配置、全厂告警认领与处置、批量文字播报、值班交接。
- 协作人员范围限定为同任务/同班组；原型用周明、李志远示例，正式权限规则需要接口实现。

## 主要走查路径

1. 登录 → 选择演示厂站 A → 工作台 → 当前任务 → 巡检记录 → 勾选检查项 → 提交 → 任务已完成。
2. 核心系统事件处置：点击顶部常驻告警条或右下“事件处置” → 核心事件列表 → 筛选“待认领” → 打开高压区越界告警 → 点击“认领事件” → 状态变更为处置中 → 点击快捷短语填写研判意见 → 提交处置说明 → 展开更多处置 → 勾选误报并复核关闭 → 查看完整处置时间线留痕。
3. 工作台 → 协作人员 → 周明 → 位置 → 轨迹 → 播放/暂停 → 昨日空态 → 返回。
4. 协作人员 → 李志远 → 离线最后位置 → 语音呼叫 → 未接通 → 返回。
5. 通讯 → 值班室视频通话 → 模拟接通 → 全屏 → 返回 → 关闭视频 → 挂断 → 最近通话。
6. 通讯底部“来电页面演示” → 模拟视频来电 → 接听或拒接。
6. 我的 → 我的设备 → 安全帽 → 信息状态 → 设备检查；安全带展示待连接状态。
7. 工作台 → 异常上报 → 输入描述 → 示例照片 → 提交 → 结果/详情 → 我的上报。
8. 消息 → 任务/反馈/安全消息 → 相应业务页。

## 设计边界与待确认

- 这是页面设计与本地交互演示，不代表硬件能力和华能接口已接入。
- 视频采用“工人安全帽上行现场画面 + 双向语音”的暂定交互；是否需要看到对方摄像头画面，由华能确认。
- 地图为原有厂区示意素材、虚构轨迹，离线人员明确展示最后更新时间。地图底图、坐标系、协作权限与查询时长待对接确认。
- 当前进行中的任务支持本地填写与完成；其他任务卡片用于状态与详情设计预览。
- 扫码绑定、相机拍摄、真实音视频、推送、消息反馈与 SOS 回执均需后续接口和真机实现。
- 本地数据刷新页面后重置；正式安卓入口未启用 WORKER_PREVIEW 时保持原实现。

## 核验

- 26 个页面在 408×900 测试视口逐页渲染并滚动检查，无布局异常。
- 自动验证检查项未完成不可提交、全部完成后状态更新。
- 自动验证视频来电接听、视频切换、挂断返回；实际浏览器走查记录见核验记录。

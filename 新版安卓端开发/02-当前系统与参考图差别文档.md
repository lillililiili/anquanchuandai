# 哪些要改（现有功能 vs 参考图）

对照：当前正式入口 `lib/wear/`（WearApp）和 9 张浅色参考图。  
读法：每一行先看「现有是否保留」，再看「要不要换皮」。不是功能缺口清单。

图上的示例人名、账号不当差异项。

---

## 0 总原则

| 类别 | 含义 |
| --- | --- |
| 保留 | 现有能力、入口、文案、路由都留下 |
| 可换皮 | 同一功能，允许改插画、卡片、颜色、列表样式 |
| 不要为了像图而改 | 改了会丢功能、改契约或改角色，本轮不做 |

旧 `lib/views` 演示页（签到、AI、围栏编辑、旧告警）本来就不是正式入口，不算「要迁回来的缺口」。

---

## 1 壳层和底栏

| 现有 | 参考图 | 结论 |
| --- | --- | --- |
| 四 Tab：工作台 / 事件 / 通讯 / 我的 | 现场 / 通讯 / 消息 / 我的 | **不要改名。** 事件红点可画成铃铛 |
| 顶栏 Logo + 厂站 ∨ + 待处理 N | 溶进插画的标题 | 可换皮，切站和待处理入口保留 |
| 登录 → 选厂站 → 工作台 | 登录页直接画了厂站 | 选站流程保留，登录页不写死厂站 |
| 新事件提示条 | 无 | 保留 |
| 通话中禁止切站 | 无 | 保留 |

## 2 按现有页面：改哪些

### 2.1 登录 `/login`

现有：品牌、主视觉、账号密码、按开关显示验证码、提交、错误文案。

| 点 | 结论 |
| --- | --- |
| 换成浅色静物插画 | 可换皮（`场景/login_stilllife.jpg`） |
| 验证码刷新并排 | 可换皮，逻辑不变 |
| 预填图上的示例账号 | 不要 |
| 登录前展示具体厂站 | 不要（现有是登录后 `/sites`） |
| 「登录遇到问题」 | 可后做静态说明，不做也不丢功能 |

### 2.2 选厂站 `/sites`

参考图没有。**整页保留**，皮肤跟登录浅色即可。

### 2.3 工作台 `/workbench`

现有（全部保留）：值班横幅、待认领 / 我负责 / 逾期 / 失去监护、人员搜索、近期事件、当前作业列表、已领用人员数 / 在用装备数、现场工具（人员、设备、轨迹、围栏、作业）、发起交接。

| 点 | 结论 |
| --- | --- |
| 加问候和日期、头图像素 | 可换皮 |
| 当前作业改成大卡（数据仍是 `activeTasks`） | 可换皮 |
| 装备缩略图（数据仍是摘要里的设备数，或点进设备/人员） | 可换皮，不要改成「登录者自己的三件装备」主叙事（值班账号 `me/equipment` 经常是空的，空态照旧） |
| 拿掉四指标 / 工具 / 交接 | **不要** |

### 2.4 事件 `/events`

现有（全部保留）：筛选、列表、详情、认领、处置评论、转交、关闭、重开、ack、草稿、409 文案、时间线、inbox 角标、演示标记。

| 点 | 结论 |
| --- | --- |
| 列表改卡片、详情加头图 | 可换皮 |
| 说明框显示字数 | 可换皮 |
| 按钮改叫「提交核验」并当成新状态 | 不要。仍是 `handle` |
| 上照片、接原安监 | 不要。`场景/site_photo.jpg` 只当空槽装饰，不接上传 |
| SOS 加示意地图 | 可换皮（标明非实测） |
| 协助组 | 不要 |

### 2.5 通讯 `/communications`

现有（全部保留）：选人、选装备、语音 / 视频（按能力）、SOS kind、TTS、「未确认现场听到」、当前会话、历史、权限隐藏。

| 点 | 结论 |
| --- | --- |
| 下拉改成可搜索的人员卡 | 可换皮 |
| 通话中全屏大画面 | 可换皮 |
| 无视频时用占位图 | 可换皮（`场景/video_placeholder.jpg`） |
| 多选组呼、打给 APP/PC 账号 | 不要 |
| 拿掉 TTS | **不要** |

### 2.6 我的 `/me`

现有（全部保留）：昵称账号厂站角色、接警状态、`me/equipment`、值班交接 / 确认接班、切厂站、退出。

| 点 | 结论 |
| --- | --- |
| 头图 + 资料改成五行卡 | 可换皮 |
| 装备改产品大卡 | 可换皮，空列表仍空 |
| 加 SIP | 不要 |
| 拿掉交接和接警状态 | **不要** |
| 设置 / 帮助 | 可后做，现有通知权限已在接警状态里 |

### 2.7 作业 `/tasks` `/tasks/:id`

现有（全部保留）：我的 / 全站、筛选、详情字段、成员、装备检查 `ok/unknown/missing`、关联事件、工作票待核实。

| 点 | 结论 |
| --- | --- |
| 详情改分区卡、成员行加点 | 可换皮 |
| 带检查画成绿勾已佩戴 | 不要（带无协议时只能未知） |
| 硬加手表列 | 不要 |

### 2.8 人员 / 设备 / 轨迹 / 围栏 / 失去监护

参考图几乎没画。**全部保留为工作台工具入口。** 换肤即可，围栏仍只读。

装备大卡视觉可用在人员详情的当前装备上，历史领用列表保留。

## 3 参考图有、现有没有：怎么办

这些不是「系统落后」，多数是图的另一种摆法或未立项能力。

| 图上的东西 | 怎么办 |
| --- | --- |
| 作业人员自己核验 | 不当新角色做。登录者就是当前 `me` |
| 智能手表设备类型 | 不新增类型。图可作登录静物；设备列表有该 type 再显示 |
| SIP | 不做 |
| 现场 4 张照片上传 | 不做。需要占位时用现成现场图 |
| 协助组 | 不做 |
| 组呼 | 不做（现计划延期） |
| 设置 / 帮助 / 登录遇到问题 | 可做静态页，不做也不挡换肤 |

## 4 视觉差（可换，不是功能差）

| 项 | 现在 | 图上 | 要不要动 |
| --- | --- | --- | --- |
| 主按钮色 | 亮青 `#35CFF1` | 饱和蓝 | 可选，换了也要保持字对比度 |
| 页头 | 白条或少量 cargo 图 | 天空插画 + 人物 | 可换，素材已备 |
| 装备 | 文字行 | 产品图 | 可换 |
| 通话 | 列表内卡片 | 大画面 | 可换 |
| 暗色 | WearApp 强制浅色 | 只有浅色稿 | 本轮继续浅色 |

现有 `assets/field-brand/cargo-v2/` 仍可继续用。新图全部在本目录 `UI素材/`，正式改代码时再拷进工程。

---

## 5 一句话

要改的是**观感**：插画、卡片、占位图、部分列表样式。  
不要改的是**功能面和信息架构**：四个 Tab 的职责、所有次级查询、事件状态机、通话规则、交接。  
图上多出来的叫法和模块，不强制对齐。

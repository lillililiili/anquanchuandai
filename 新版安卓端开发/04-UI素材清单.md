# UI 素材清单

全部位于 `新版安卓端开发/UI素材/`。正式改代码前不要拷进 Flutter 工程。

来源两种：

- **裁剪**：从 9 张参考图切出，在 `裁剪原稿/`，带一点界面边，适合再修。
- **成品**：按裁块或参考图生成 / 去 UI 后的可用图，开发占位用这些。

图上的人名不是素材需求。角色是通用卡通作业员，给页头装饰。

## 和现有工程素材的关系

工程里已有 `assets/field-brand/cargo-v2/`（logo、login-hero、工具卡等）。  
本轮**不替换它们**。新皮肤需要头图 / 产品图时，实现阶段再把上表成品拷进工程并写 `pubspec.yaml`。  
cargo 工具卡（人员、设备、轨迹、围栏、作业）没有参考图对应物，继续用原卡即可。

## 接入时的占位规则

1. 每个 `Image.asset` 设宽高或比例，并写 `errorBuilder`。
2. 装饰图 `excludeFromSemantics: true`，不要当按钮。
3. 地图、通话占位图上用现有文案叠「非实测 / 演示 / 待加入」，不要把占位图解释成实时画面。
4. 不要把角色图当成当前登录者头像的唯一来源；有用户头像字段再用字段，没有再用卡通 bust。

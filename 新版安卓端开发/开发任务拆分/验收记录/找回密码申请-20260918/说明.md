# 找回登录权限／申请重置密码 · 2026-09-18

入口：登录页「忘记密码 / 申请重置」。独立页面按照用户参考图制作，使用现有浅蓝背景、ROLLING、工作人员插画、白色圆角卡片与蓝色按钮。

## 页面内容

- 顶部返回登录、Logo、界面预览标识；头图包含「账号与访问」「找回登录权限」和安全提示。
- 工作账号：自动带入登录页已输入的账号，可编辑；为空时提示填写。
- 图形验证码：4 位演示字符，可刷新，不区分大小写校验；刷新后清空验证码输入。
- 提交密码重置：先校验填写内容，随后准确提示当前申请服务尚未接入，申请未发送、密码未变更。
- 底部说明：申请不代表密码已重置，需要管理员确认。页面适应键盘弹出、小屏和大字号，可滚动到底部。
- 返回登录后保留原登录页的账号、密码输入，不改变会话。

## 接口边界

已检索后端及 PC 调用：目前存在 `/system/user/resetPwd`，由 `system:user:resetPwd` 权限保护，作用是管理员直接重置密码；未发现供未登录用户提交找回申请的接口。本页不调用该管理员接口，不收集新密码，不创建假申请记录。

原登录入口的底部弹窗没有发请求却提示“申请已记录”；本轮将其替换为独立申请页，并移除该错误成功提示。图形验证码为本地 UI 演示，不作为服务端安全校验。后续接入申请服务时，需要使用该服务支持的验证码签发及校验协议。

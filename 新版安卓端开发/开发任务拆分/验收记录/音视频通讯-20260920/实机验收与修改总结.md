# 安卓通讯与虚拟安全帽联调验收

日期：2026-09-20。承接用户本轮通讯联调要求；保留原界面风格、底部导航与业务接口，不恢复亮暗切换。

## 直观修改

1. 通讯页增加组合筛选：班组、在线状态、设备类型（安全帽/腰带/手表）、作业组。同类多选满足任一项，不同类别同时满足；隐藏的选择自动清除，人员与设备重复选择会按设备去重。
2. 增加语音、视频、群组通话页面：统一蓝色背景、白色圆角卡片、计时和通话按钮。视频使用明确标注的示例画面，可全屏预览。通话页返回后可从提示条重入；在通话页内不重复覆盖提示条。
3. 值班账号在应用前台的任意页面可收到普通或 SOS 来电弹窗。SOS 使用醒目的紧急样式。正在建立或进行通话时保留厂站/账号切换保护。
4. 网页 `/business` 增加多人、多设备模拟在线、异常标记、模拟佩戴配置、逐设备接听/拒接/挂断及播报确认。读取现有人员、设备、班组和作业，不批量创建虚拟人员。
5. 作业详情增加“调整人员”，使用原有业务成员增删接口；通讯的作业组筛选采用同一成员数据。首页当前作业右上角增加无底色的“全部作业”，与原现场工具入口同路由。

## 雷电与网页实际联调

设备：雷电 `emulator-5554`，Android 包 `com.rolling.intelligence_headband`。安卓使用现有 `siteA_duty`（厂站 A），网页使用现有管理员账号；密码未记录。选用原有演示安全帽 RL-H001（陈建国）和 QA-H002（周明）。

| 实测场景 | 观察结果 |
| --- | --- |
| 网页安全帽普通语音呼入 | 安卓首页弹出接听/拒接；接听后网页和安卓均显示接通 |
| SOS 视频呼入 | 值班端紧急来电弹窗，接听进入视频示意页；安卓挂断后网页同步结束；最终部署的服务再次复测通过 |
| 安卓语音外呼 | 网页显示设备响铃，网页接听后两端接通；网页挂断后安卓结束 |
| 网页拒接安卓外呼 | 网页状态变为已拒接，安卓通话终止 |
| 两台设备视频群呼 | 网页两台分别接听，安卓显示两名参与者；一台挂断后另一台仍通话，全部挂断后结束 |
| 群发文字播报 | 安卓对两台设备提交，网页收到同一批文本；逐台模拟确认后安卓回执更新 |
| 在线＋安全帽筛选 | 列表从 72 项缩小为 4 项：2 个人员入口及其 2 台设备入口，选中人员群呼解析成 2 台而非重复 4 台 |
| 首页全部作业 | 进入原有作业任务页面，保留“我的任务/全站作业” |
| 作业人员调整 | “东区巡检”原 1 名参与者，临时加入演示人员03后回读为 2 人，再删除该临时成员并确认恢复为 1 人 |
| 通话页顶部/底部/返回 | 检查语音、视频及群呼底部操作；验证视频全屏与返回；修复通话页重复悬浮条及长账号昵称溢出 |

实测生成的 SOS 为后端真实保存的**演示事件**，仍在消息列表中可查；未伪装为生产事件，未删除审计记录。测试完成已结束通话，并关闭自动化测试网页、将测试设备模拟在线状态关闭。需要继续测试时，在网页重新勾选设备上线。

- 最终调试 APK 构建成功并覆盖安装到雷电，Docker 联调服务已重建。

## 边界与复用

- 本轮“接通”仅表示双方呼叫信令状态一致。没有采集/传输真实麦克风或摄像头，没有验证实际声音、视频流或真实扬声器播报。
- 应用内前台轮询来电，不包含安卓应用被杀、锁屏或系统后台推送能力。
- 普通通信允许测试专用虚拟佩戴；SOS 需与设备真实佩戴绑定一致，否则拒绝发起，避免事件人员与来电人员不一致。
- 模拟在线、呼叫和播报回执保存在联调进程内存，重启清空；作业成员操作与 SOS 演示事件走真实业务接口并持久化。
- 本机部署 APK 开启 `CALL_LAB_ENABLED=true`；默认构建关闭该开关，沿用既有真实通话接口与 Agora 通路。真实 Agora 媒体互通不属于本轮验收结果。
- 启动、账号与联调操作见同目录《联调使用说明》。网页入口：`http://localhost:5188/business`。
- 本轮修改前的部分文件备份位于项目根目录 `垃圾桶/2026-09-20-通讯联调整改前/`，内部保留原相对路径。工作区原有变更未回退；没有执行 Git 提交或推送。

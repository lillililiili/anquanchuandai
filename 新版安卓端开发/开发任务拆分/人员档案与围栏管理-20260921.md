# 安卓人员档案与电子围栏管理 · 2026-09-21

## 范围

现场工具原有入口保留：人员档案 `/people`、电子围栏 `/fences`。新增页面沿用浅蓝背景、白色圆角卡片、蓝色按钮、ROLLING 标识及底部导航。

## 人员档案

- 管理员可新增、编辑、启用/停用人员；维护班组、承包商及有效期、授权厂站。
- 编辑时保留原有关联账号、部门和厂站授权，提交版本号防止覆盖过期数据。
- 人员详情支持库存装备分配、当前装备归还；沿用领用接口、厂站权限和幂等键。
- Excel 模板下载、导入、导出使用主后端既有接口与安卓系统文件选择器；导入显示行号及校验错误，HTTP/JSON 错误不会被当作 Excel 保存。
- 普通只读账号不展示管理按钮，服务端继续按原权限校验。

## 账号找回与重置审批

登录页“忘记密码 / 申请重置”已接入实际申请接口，填写账号或人员编号、姓名、联系方式及说明。服务端验证码与 IP 限流生效；提交回执不透露账号是否存在。

管理员在人员档案 → 重置审批查看申请，搜索核实真实账号，填写核实说明和新密码后批准，或填写原因驳回。密码以原系统哈希方式写入，不保存到申请记录；批准提交后旧会话失效。重复审批返回冲突。内置超级账号不通过人员找回通道重置。

新增接口 `/api/v1/account-recovery/requests`、`/accounts`、`/requests/{id}/approve`、`/reject`。数据库迁移 `V015__account_recovery.sql` 已应用到 Docker MySQL。

## 电子围栏

- 新增与编辑地图多边形：点选增加顶点、点编号再点地图调整位置、撤销/删除顶点、清空、经纬度定位。
- 支持启停、进入/离开触发、防抖、生效时段、全厂站/指定人员多选。
- 与 PC 共用围栏接口与数据；补齐编辑接口保存启停状态，校验坐标、顶点、时段和人员厂站归属。
- 新增 `/api/v1/fences/map-tiles/{z}/{x}/{y}`，底图经主后端鉴权、缓存后返回。安卓不直接请求外部底图。
- 无现场坐标的新围栏明确提示地图只是浏览起点，不能视为设备实时位置。

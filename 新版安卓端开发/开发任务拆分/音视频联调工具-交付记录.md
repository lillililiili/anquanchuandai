## 范围

- 工具目录：`../音视频网页联调/`（原 `call-lab`），Docker Compose 部署，单个 Node 容器。
- 网页测试身份切换，呼叫、接听、拒接、取消、挂断、超时、断线状态。
- 合成音频与动态测试画面，不请求麦克风或摄像头。
- Agora 模式用于安卓设备联调；WebRTC 模式用于无需密钥的网页自检。
- 提供 Headband 厂商接口适配和业务 API 转发，网页拒接/结束可同步同一 Java 会话。
- 测试配置及可选后端 Compose 覆盖均在工具目录。未改变既有安卓、Java、PC 源码；未切换现有业务后端。

## 验收

- 服务测试 8 项通过：会话状态、双端媒体确认、身份/SN 冲突、越权信令、离线/忙线、超时/断线、厂商凭证接口、业务会话结束同步。
- Chrome 双上下文通过双向音频及视频传输：解码视频 640×360，双方实际接收字节增加。
- 真实设备采集调用次数为 0。
- 反向呼叫、拒接、暂停测试音/画面、挂断后轨道释放、关闭对端窗口、账号切换通过。
- 390px 手机布局及桌面截图已检查；无横向溢出，浏览器无脚本错误。
- Agora Web SDK 可创建并释放合成音视频轨道；不需要设备权限。
- Docker 容器健康检查通过，访问地址 `http://localhost:5188`。

## 已知边界

- 用户目前没有声网测试项目凭证；配置入口已准备，真实 Agora 网络和安卓端到端联调未执行。
- 网页间双向呼叫已实现。现有安卓没有来电接听入口，本次未修改安卓；现有厂商链路支持安卓主动呼叫网页模拟安全帽。
- 长通话时安卓凭证续期仍受现有 Java 只读取缓存的实现限制。
- 业务后端的厂商请求缺少 video 标志，因此网页接收外部安卓呼叫统一按音视频数据源发送，语音安卓只订阅音频。

配置、启动、测试和恢复操作详见 [工具 README](../音视频网页联调/README.md)。浏览器测试原始结果和截图在 `../音视频网页联调/artifacts/`（本地生成，不纳入 Git）。

# 安卓全页面设计 当前预览版

直接双击本目录的 **index.html** 打开展示。无需安装软件、启动后端或登录账号；整个文件夹复制到其他电脑后也可离线使用。

本版根据 `android代码/melhat_android-main` 的当前工作区生成，包含未提交的最新改动。参考“安卓全页面设计-浅色多彩版”的编号与模块组织，展示当前已经存在的安卓组件，不将参考设计当成开发完成状态。

## 展示内容

- 42 个页面、弹层、功能区及状态：沿用参考版 01–40，并补充 41 加载中、42 切换账号。
- 首页支持模块筛选、关键词搜索和父子关系树。
- 每项都有主要父页面、子页面、跨模块入口、当前实现说明及源码位置。
- 详情可切换完整长图与逐屏截图。分屏保留重叠内容，标注真实滚动距离，覆盖页面顶部和底部。
- 长图按实际滚动位移拼接，重复的固定区域只出现一次；可下载完整图片。
- 当前版本没有亮暗切换。

画面直接使用当前 Flutter 页面、图片资源、Logo、颜色、按钮和导航组件渲染。采集画布为 360×616 逻辑像素，输出为 3 倍分辨率；不含安卓系统状态栏。中文使用项目网页包中的 Noto Sans CJK SC，测试渲染环境的默认占位字体仅在采集时映射到该字体。它是源码渲染截图，**不是雷电模拟器的设备截屏**。

此网站是可点击浏览的页面展示库；图中的业务按钮是截图内容。页面关系由展示库中的链接操作。

## 当前实现边界

所有人员、装备、作业、事件、厂站、权限和记录均为本地示例数据。为了覆盖条件页面，截图适配器注入离线设备、待确认关联事件、待接班记录和请求失败等状态，未请求业务服务器。

1. 账号重置弹层目前只给出联系管理员提示，没有调用重置接口。
2. 语音、视频及文字播报有现成界面和接口调用代码；截图中的会话是演示会话，不代表真实设备、RTC、摄像头或麦克风已联调。
3. 核验附件为示例照片交互，未上传服务器。SOS 示意地图和协助组体验沿用安卓当前实现；协助组服务尚未接入。
4. 通知状态没有启动真实推送，展示“通知权限未开启”不能视为真实手机权限结论。
5. 轨迹页面可以进入人员选择状态；当前源码在选中人员、轨迹数组为空时会因提前构造 `_trackBody()` 触发 `ArgumentError`。13/16 展示可进入的原始页面，13 标注这一问题。诊断原图与说明保留在 `diagnostics/轨迹空数据异常/`。未在本任务中修改安卓业务代码。
6. 围栏演示数据没有几何边界，失去监护列表的示例装备均正常，因此对应页面保留无边界或空数据的实际显示。

这些说明用于区分界面已经实现、示例状态以及尚待真实联调的能力，不代表全系统验收完成率。原 `开发任务拆分` 目录本次读取时为空，未依据历史删除文档推断任务完成率，也未覆盖或恢复该目录。

## 文件结构

| 文件 / 目录 | 内容 |
| --- | --- |
| index.html | 离线展示入口 |
| pages/ | 每个展示项的独立页面 |
| 页面图片/ | 完整长图和首屏缩略图 |
| captures/ | 未去重的原始分屏、滚动位置元数据 |
| 页面总览.jpg | 全部展示项联系表 |
| 页面入口关系.md | 完整入口、父子关系和实现边界表 |
| manifest.json / manifest.js | 页面目录、关系、截图尺寸和来源 |
| 源码校验.json | 生成时的安卓源码 SHA-256，用于识别后续变化 |
| 网页验收.json | 浏览器检查结果 |
| tools/ | 采集、拼接、生成和验证脚本及日志 |

## 后续更新

在已配置 Flutter 的原开发环境运行 `tools/重新生成.ps1`。脚本使用独立测试进程采集各页，避免页面共享状态在测试间残留；然后重新生成长图和展示页。源码更新后若文案或入口变化，需同步 `tools/capture_test.dart` 的采集动作和 `tools/build_gallery.py` 的入口说明。

本次未修改正式安卓源码、后端或参考设计目录，未部署或覆盖雷电安装包。

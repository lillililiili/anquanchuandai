## 已知的原项目检查差异

较早一次扩大测试中，`wear_equipment_reference_test.dart` 的旧高度断言要求装备区为 558.92，而当前布局测得 549.0，相差 9.92 逻辑像素。日志保留于 `flutter-test.log`。本次按当前安卓布局同步，未为满足旧断言改变页面高度，也未修改该断言；装备接口和历史查询相关测试在那次执行中通过。

最终构建也包含同步期间更新的轨迹页面；轨迹入口提供当前查询页和明确标记的示例预览，实时地理数据不接入。

## 页面父子关系

| 父页面 | 子页面或弹层 |
| --- | --- |
| 登录 | 厂站选择 → 现场 |
| 现场 | 作业详情、人员查询、设备查询、轨迹回放、围栏查询 |
| 作业详情 | 参与人员详情、设备详情、异常核验 / SOS、联系监护人 |
| 人员详情 | 当前装备、历史领用记录 → 设备详情 |
| 设备详情 | 通讯操作（对讲 / 视频 / 文字播报） |
| 消息 | 筛选弹层、异常核验、SOS 协助 |
| 我的 | 我的装备、设置、帮助与反馈、切换厂站、切换账号 |
| 我的装备 | 装备详情、绑定历史 |

返回行为直接使用当前安卓导航。相同详情可以由不同入口打开，返回目标随来源页面而变化。

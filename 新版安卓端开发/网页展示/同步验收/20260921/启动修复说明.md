# Windows 启动入口修复

故障：双击“打开安卓演示.cmd”后窗口闪退，没有打开网页。

复现命令（在展示目录）：`cmd.exe /d /c "打开安卓演示.cmd"`。

修复前退出码为 1，输出 `'01' is not recognized` 和 `'ll.exe' is not recognized`。同时本地服务健康检查为 200，说明问题发生在批处理解析阶段，而不是 Flutter 网页加载或服务端。

原始批处理为 UTF-8 无 BOM、LF 换行（CRLF 数量 0）。CMD 执行 `chcp 65001` 后读断了后面的命令。仅将换行转换为 Windows CRLF，保持命令内容不变，再执行同一入口，退出码变为 0、无错误输出。停止入口存在同样的换行问题，一并修复。

验收：停止原服务后，通过修正的 CMD 冷启动成功，健康检查及首页均返回 200；服务已运行时，再次执行启动入口返回 0。`tools/check_launcher.py` 检查实际 CMD 入口、CRLF 格式、服务复用与首页交付。打包脚本在发布前固定两个 CMD 的 CRLF 换行，避免后续打包回归。

本轮未修改安卓主项目、网页页面组件或业务数据。原错误 CMD 保存在本目录的“启动故障原文件”文件夹，可直接比较。

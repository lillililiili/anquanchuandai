# 页面父子关系

以当前安卓 `lib/wear/app.dart` 和各页面实际按钮为准。底部四个主页面为现场、通讯、消息、我的。左侧目录是展示辅助入口，不改变手机内布局。

| 父页面 | 子页面或弹窗 | 进入方式与返回 |
|---|---|---|
| 登录 | 选择厂站 → 现场 | 登录页进入；展示登录不会验证真实账号 |
| 现场 | 作业列表 → 作业详情 | 作业卡片或作业入口；详情可返回列表 |
| 作业详情 | 人员详情、设备详情、关联事件、装备检查 | 点击成员、装备或相关按钮；返回父页面 |
| 现场 | 人员列表 → 人员详情 | 人员入口；人员详情可查看当前装备、历史领用、轨迹和关联事件 |
| 现场 | 设备列表 → 设备详情 | 设备入口；设备详情保留当前归属、状态、历史记录等区域 |
| 现场、人员详情 | 轨迹回放 | 选择人员和时间段；播放、速度、进度及示例入口沿用安卓 |
| 现场 | 电子围栏列表 → 围栏详情 | 围栏入口；查看区域和规则 |
| 现场 | SOS 列表 → SOS 详情 | SOS 卡片或列表；详情通过安卓事件页面承接 |
| 通讯 | 联系对象筛选 | 展开筛选区域，按人员、设备与状态查看 |
| 通讯 | 联系人操作、呼叫页、播报弹窗 | 联系人按钮或多选；仅演示本地状态，无真实语音或视频 |
| 消息 | 事件筛选弹窗 | 筛选按钮，保留类别、状态等安卓选项 |
| 消息 | 事件详情 → 关联人员、设备、作业 | 点击事件卡片；详情可继续查看事件记录和相关对象 |
| 事件详情 | 认领、处置、复核、转交等弹窗 | 按当前事件状态显示按钮；操作仅改变本页内存 |
| 我的 | 通讯服务状态 | 点击“查看状态”；关闭后回到我的 |
| 我的 | 我的装备 → 装备详情、领用历史 | 点击“我的装备”；此页由安卓内部导航进入，无单独 URL |
| 我的 | 设置 → 相关确认弹窗 | 设置按钮；切换账号、退出等按钮保留原有确认流程 |
| 我的 | 帮助与反馈 | 点击对应行；关闭返回我的 |
| 我的、顶部厂站按钮 | 选择厂站 | 切换后按所选厂站重新读取本地快照 |
| 交接记录 | 提交/确认 | 沿用安卓页面提供的入口；记录只在本地变化 |

长页面在手机内部连续滚动。四个主页面保留底部导航，子页是否显示底部导航沿用当前安卓实现。浏览器回退和页面返回按钮使用安卓现有导航逻辑。直接从辅助目录进入深层页面时，优先使用页面中的返回入口。

# 新版安卓端文档说明

日期：2026-09-16（第二轮）  
本轮仍**不改代码**。图片、分析、开发说明全部只放本目录 `新版安卓端开发/`。正式改 Flutter 工程之前，不要往 `android代码/` 里拷素材或改页面。

## 本轮要回答的两件事

1. **哪些要改**：现有 WearApp 哪些地方值得换成参考图那种浅色插画观感。  
2. **怎么改**：在**不丢任何现有功能**的前提下，每一页怎么铺视觉、哪些名字和结构可以不动。

参考图里的人名、账号、厂站、设备号（例如图上的作业人员、`chenjg_demo`、`RL-H001`）只是设计稿填的例子，**不必单独处理，也不当产品角色需求**。开发时一律走当前登录用户和 `/api/v1` 返回值。

## 三条硬规则

1. **现有功能全部保留。** 工作台四指标、事件认领/处置/转交/复核/重开、TTS、交接、选厂站、人员/设备/轨迹/围栏只读/任务/失去监护，新页面都要进得去、用得了。参考图没画到的入口，改成次级入口或换个摆法，**不能删**。
2. **名字和显示方式与图不同，不强制改成图上的样子。** 底栏继续叫「工作台 / 事件 / 通讯 / 我的」。按钮继续用现有文案（认领、处置、打开事件中心）。图上的「现场 / 消息 / 提交核验」只是另一种叫法。
3. **视觉可以靠近参考图。** 浅蓝天空、白卡片、卡通角色、装备产品图、示意地图，用本目录素材占位，避免以后布局空一块。契约里的未知 / 演示 / 待联调文案照旧，不因为插画就画成已接通、已扣好。

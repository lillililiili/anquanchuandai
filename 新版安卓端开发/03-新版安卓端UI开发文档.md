# 怎么改（UI 开发说明）

在现有 `WearApp` 上换浅色插画皮肤。**路由、权限、接口、状态机不动。**  
实现阶段才改 `lib/wear/`；本文件只规定改法。素材先用本目录 `UI素材/`。

---

## 1 改法总则

1. 每个现有页面先列出现有块，再决定哪几块套插画。套完必须还能完成原来的操作。
2. 参考图用来看疏密、圆角、头图，不用来改 Tab 名、按钮名、业务对象。
3. 接口没数据就空态，不要用图上的示例人填满首页。
4. `demo: true`、未知、待加入、未确认听到，文案保持现在这套。
5. 新插画用 `Image.asset` 铺在现有 `WearCard` / `WearPageHeader` 后面或右侧，控件不要被图挡住。

代码落点（实现时）：`lib/wear/ui.dart` 扩颜色和头图组件；各页 `build` 换布局。不要新写一套业务层。

---

```
/login → /sites → 四 Tab
  工作台 /workbench
  事件   /events
  通讯   /communications
  我的   /me
次级（工作台或我的进去）
  /people /people/:id
  /devices /devices/:id

  /fences /fences/:id
  /tasks /tasks/:id

```

底栏标签保持「工作台、事件、通讯、我的」。  
事件 inbox 红点保留。  
壳层切厂站、待处理、WS 提示条保留。

## 3 逐页：怎么改

下面「现有块」都必须还在。「视觉」是可选叠法。

### 3.1 登录 `/login`

现有块：Logo 与标题、hero 图、账号、密码、验证码（可关）、登录、错误。

怎么改：

- hero 换成 `UI素材/场景/login_stilllife.jpg`，键盘弹出仍隐藏装饰（现逻辑）。
- 背景可用 `背景/sky_header.jpg` 作顶部渐变。
- 表单结构不动。验证码开着时，图 + 输入 + 刷新可以排成一行，逻辑仍走 `/captchaImage`。
- 成功后仍进 `/sites` 或工作台，不要在登录页画当前厂站。

### 3.2 选厂站 `/sites`

现有块：授权列表、空态、通话中禁用。

怎么改：浅色卡即可，不必强做成某张参考图。

### 3.3 工作台 `/workbench`

现有块（顺序可调，不能少）：

1. 值班横幅（待办文案 + 进事件 + 发起交接）
2. 人员搜索
3. 四指标：待认领 / 我负责 / 逾期 / 失去监护
4. 近期未关闭事件
5. 当前作业
6. 已领用人员 / 在用装备
7. 现场工具五入口

怎么改：

- 顶区可加问候（`me.nickName`）和日期，右侧放 `角色/character_avatar.jpg` 或 `背景/sky_header.jpg`。
- 「当前作业」可做成参考图那种大卡：标题、区域、票号（待核实规则不变），右侧 `场景/work_scene.jpg`。多条作业仍进 `/tasks`，「全部作业」留着。
- 四指标不要收进「我的装备」里藏起来；可以放在作业卡下面。
- 现场工具可继续用现有 cargo 卡，或改成白列表，入口一个不能少。
- 不要把本页改成只显示 `me/equipment`。装备大卡放在「我的」或人员详情。

### 3.4 事件 `/events`

现有块：筛选、列表、详情、认领/处置/转交/关闭/重开、草稿、时间线。

怎么改：

- 页头可铺 `角色/character_clipboard.jpg` 或工作台卡图，标题仍叫「安全事件」或现有「安全事件」。
- 详情 SOS：在位置区下面加 `场景/plant_map.jpg`，角落标明「厂区示意 · 非实测」。有坐标再打点；没坐标只显示示意图 +「位置未知」。
- 处置区可做成大输入 + 草稿 / 提交两按钮，**提交仍是现有 handle**。不要加相册控件当功能。
- 列表空态、冲突 409、只读无写按钮，保持。

### 3.5 通讯 `/communications`

现有块：联系对象（人 + 装备）、发起语音/视频、TTS、当前会话、历史。

怎么改：

- 人员下拉可改成搜索 + 单选卡片，数据仍是 `people/options`。
- 无 intercom 的设备电话按钮禁用，文案保持「该设备不支持通话」。
- 当前会话可全屏：大画面 + 麦 + 挂断。无远端 / demo 用 `场景/video_placeholder.jpg`，并保留「示例 / 演示 / 待加入」而不是「已接通」。
- TTS 卡不要拿掉。扬声器、全屏按钮有就加，没有就仍用现有两个按钮。

### 3.6 我的 `/me`

现有块：身份卡、接警状态、装备面板、值班交接、切厂站、退出。

怎么改：

- 头图用 `角色/character_thumbsup.jpg`，口号贴纸可用 `贴纸/slogan.png`（装饰）。
- 身份改成几行键值：姓名、账号、厂站、角色（现有角色映射表）。
- 装备面板改产品卡：`helmet` 用 `装备/helmet.jpg`，`belt` 用 `装备/belt.jpg`。其它 type 有数据再用通用图或 `watch.jpg`，没有就不要空画一张表。
- 交接、接警、退出保持原位置，可放到资料卡下面。

### 3.7 作业详情 `/tasks/:id`

现有块：字段卡、成员、装备检查、关联事件。

怎么改：

- 分区卡。成员行用绿 / 灰点表示帽、带检查结果（`ok` / `unknown` / `missing`）。带不得画成已扣好。
- 「联系该人员」类按钮：有 personId 就进现有通讯路由。作业详情若要加「联系监护人」，也是跳 `/communications?personId=`，不新接口。

### 3.8 其它查询页

人员、设备、轨迹、围栏、失去监护：换 `WearCard` 和页头插画即可。围栏只读、轨迹质量字段、演示标记都不改语义。

## 4 占位图怎么用（避免布局空缺）

实现时每个插画槽都指定宽高或 `AspectRatio`，图用本目录成品：

| 槽 | 文件 | 用在 |
| --- | --- | --- |
| 登录静物 | `场景/login_stilllife.jpg` | 登录 hero |
| 页头天空 | `背景/sky_header.jpg` | 工作台 / 我的 / 通讯顶 |
| 角色点赞 | `角色/character_thumbsup.jpg` | 我的、作业 |
| 角色打电话 | `角色/character_phone.jpg` | 通讯 |
| 角色对讲 | `角色/character_walkie.jpg` | SOS 详情头 |
| 角色持板 | `角色/character_clipboard.jpg` | 事件详情头 |
| 头像 | `角色/character_avatar.jpg` | 工作台问候 |
| 盔 / 带 / 表 | `装备/*.jpg` | 装备卡、登录 |
| 作业现场 | `场景/work_scene.jpg` | 工作台作业卡 |
| 厂区示意 | `场景/plant_map.jpg` | SOS 位置 |
| 通话占位 | `场景/video_placeholder.jpg` | 未接通画面 |
| 现场照片槽 | `场景/site_photo.jpg` | 仅装饰，不接上传 |
| 警告 / SOS 泡 | `贴纸/warning_triangle.jpg` `sos_bubble.jpg` | 事件、SOS |
| 手写口号 | `贴纸/slogan.png` | 装饰 |
| 字标 | `贴纸/logo_wordmark.png` | 可与现有 `logo.png` 并存 |

加载失败用 `errorBuilder` 退回纯色，不要让整页高度塌掉。

正式改代码时，再把需要的文件拷进 `android代码/melhat_android-main/assets/`，并登记 `pubspec.yaml`。**现在不要拷。**

## 5 建议实现顺序（仍是换肤，不是新功能）

| 步 | 动哪 | 完成标准 |
| --- | --- | --- |
| 1 | `ui.dart` 头图组件 + 可选主色 | 现有页先不拆功能 |
| 2 | 登录、选站 | 验证码与进站流程与现在一致 |
| 3 | 工作台 | 横滑 / 1.5 字号下四指标和工具仍可点 |
| 4 | 我的、装备卡 | 交接、退出仍在 |
| 5 | 事件列表 / 详情、SOS 地图装饰 | 认领处置回归仍过 |
| 6 | 通讯卡片 + 通话占位图 | TTS 和能力门禁仍在 |
| 7 | 任务详情与次级页换卡 | 入口都能从工作台走进去 |

每步跑现有 `test/wear_*_test.dart`。换肤不得删行为断言。

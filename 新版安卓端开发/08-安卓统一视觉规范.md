## 当前视觉规则

- 保留蓝白工业风格、对应页人物／场景、产品比例、白卡和蓝色主要操作；不新配整套色表。
- 现场、通讯、消息、我的四栏及原图标不改；我的60dp底栏是已授权局部比例，其他分支保持原值直至具体任务核对。
- 字体层级、卡片边界和留白按图逐页校准；普通视口看图，大字体与短屏通过换行和滚动保持可操作。
- 颜色不能作为唯一状态提示；错误、未知、离线、未开通须有可理解文字。真实图片、验证码、附件与视频保持原色。
- 无独立参考图页面保持原结构，只修具体可读性和跳转；不新增统一顶栏或整页模板。
- 我的参考图中姓名和示例状态不硬编码；人物背景与文字、Logo、可点击控件分开。
- 原深色参考图留作历史资料，不要求生成配对背景、保存外观偏好或提供外观按钮。

## 4. 壳层、组件与排版

### 4.1 旧壳层分析（已失效）

主页面顺序为系统状态栏、应用顶栏、授权上下文（需要时）、页面内容、底部三入口、安全区。次级页顶栏用返回、页面标题；登录页用品牌，无底栏、无厂站。通话与SOS关键页面保留简洁顶栏和固定操作区，不在视频上叠加装饰导航。

全局SOS采用可辨识、非循环闪烁的紧急条或弹层，显示人、位置、来源设备和进入通话动作。不能因页面刷新关闭，不能只依靠红点提示。已有通话时展示新SOS提示与查看入口，不自动挂断当前通话。

厂站是授权后的全局上下文：选择一次同步通讯、告警和位置页。切换厂站时对已有通话与草稿的处理由业务流程管理，不隐式清理。

### 4.2 组件统一

| 组件 | 布局与语义 |
| --- | --- |
| 顶栏 | 一行主标题，返回位置固定；长厂站名允许两行或单独上下文行，不挤掉返回入口 |
| 底栏 | 通讯／告警／我的；图标加文本，当前项用工业蓝及选中标记双重识别；未处理数与未读数含义分开，不用一个红点替代全部状态 |
| 人员行 | 姓名优先，角色／班组其次；展示可联系端、能力及必要位置；设备编号为辅助信息，已选、在线、忙线分开表达 |
| 装备行 | 类型、编号、绑定人、在线／离线／未知、最新数据时间；按能力显示挂钩、带扣、气体等字段，没有能力不凭类型猜测 |
| 告警行 | 类型、等级、状态、人、位置摘要、时间；统一流水，帽／带／气体／无票等只作筛选；可有细状态标记，不做彩色卡片墙 |
| 状态标签 | 图标＋明确文字，状态颜色用于小范围标记；“离线”“未知”“数据过期”“能力待确认”彼此独立 |
| 表单 | 持续可见的字段名、值、帮助与错误；错误靠近字段，保留用户输入。后续若批准并接通附件功能，应包含上传进度、失败重试、删除名称，不只显示缩略图 |
| 主次按钮 | 每个操作区一个主要推进动作；工业蓝实心为主，次级为中性底／边界，危险操作有文字与图标。无能力入口不出现；已有能力但暂不可用，禁用并解释原因 |
| 提示与弹层 | 使用主题面板，明确标题、影响与动作；弹层关闭不丢表单，阻断失败提供重试／返回。提交成功仅据真实响应显示 |
| 空态 | 轻量图标、事实说明、适当下一步；不使用大人物插画，不把“暂无数据”写成“全部安全” |
| 地图／楼层与视频容器 | 固定稳定容器，状态提示与媒体本体分层；来源、时间、楼层／精度、是否实时有清楚标签 |

### 4.3 移动端建议尺寸

下列为移动适配建议，不是客户PC尺寸原文：以dp管理间距、sp管理文本；页面横向边距16dp，组间距16—24dp，行内间距8—12dp；圆角8—12dp；细线1dp。顶栏基准56dp，触控热区至少48×48dp；文字放大后允许行高与容器扩展。正文优先16sp、辅助14sp、页面标题20—22sp；客户8.3的中文无衬线及层级原则保持，不能将PC的13—14px直接当手机固定字号。

字体优先系统可用中文无衬线，支持Noto Sans SC；编号、KKS与时间可用等宽。图标使用同一家族、统一线宽、默认24dp，不混用彩色贴纸和线性图标。密度用列对齐与分组优化，不压缩关键字号；列表长名称换行，设备号可复制，重要告警位置不得仅以省略号隐藏。



## 5. 页面统一布局

| 页面 | 自上而下的固定信息顺序 | 关键约束 |
| --- | --- | --- |
| 登录 | 品牌 → 产品标题／客户说明 → 账号 → 密码 → 服务要求的验证码 → 错误区 → 进入值班台 → 帮助 | 一屏一张卡；键盘或大字时可滚动；密码不因页面刷新清空或暴露；不显示厂站／真实人员；无装饰插画和视频 |
| 通讯 | 顶栏及厂站 → 服务可用性 → 搜索／必要筛选 → 联系人与最近记录 → 已选对象及发起端 → 主呼叫动作 | 人员先行；手机或本人绑定设备发起；组呼、帽侧发起、TTS需求保留并以能力／服务决定可用性，不将待联调结果包装成正常通话 |
| 告警 | 顶栏及厂站 → 状态／类型／等级筛选 → 未处理优先的统一列表 | 不做数据大屏；未知数量显示“暂不可用”，不能显示0；只读与可处置权限分别显示 |
| 告警详情 | 等级／状态及标题 → 人与设备 → 分层位置／来源／时间 → 事件证据及处置记录 → 联系／位置／获授权的确认处置 | 独立页；多个来源统一关联；返回恢复列表筛选与位置；核验表单按需展开，不能将全部告警都改为“异常核验” |
| 我的 | 身份摘要 → 授权厂站／角色 → 我的装备／接警状态 → 外观与设置／帮助 → 退出 | 无大人物头图；退出后可重新登录其他账号，不新增独立多账号管理；账户动作与业务动作分组；隐私信息按权限展示 |
| 人员／装备详情 | 对象身份 → 当前可用能力 → 状态及更新时间 → 人员／设备关联 → 位置／告警／联系 | 一人多设备；安全带状态按协议展示“未系／未挂钩／未知”，通信断连不等于未挂钩；预留气体等后续设备类型与能力 |
| 现场／作业上下文 | 厂站与区域／层 → 来源票与人员 → 本人及相关设备 → 关联告警／联系 | 次级页；来源不存在即显示未关联，不编票号、许可、责任人或班组 |
| 位置／楼层 | 对象及位置状态 → 区域／层／高度文字 → 二维或分层示意 → 来源、精度、时间 → 关联人员／告警 | 同一人只一处当前点；过期来源不标实时；没有层信息明确“楼层未知”；不以游戏场景替代位置可读性 |
| 通话 | 对方／发起端 → 连接阶段与媒体 → 通话状态 → 静音／扬声器／全屏 → 挂断 | 状态包括呼叫中、振铃、接通、重连、失败、结束；音视频按能力；全屏仍有退出与明确控制 |
| SOS | 紧急状态 → 人／设备 → 分层位置及时间 → 通话／协助对象 → 处置记录与获授权动作 | 无视频来源优先解析同一人绑定的在线视频安全帽，保留历史来源；无终端明确不可用，不自动改呼别人；结束通话不等于事件处置完成 |
| 核验／设置／帮助 | 标准顶栏 → 分组内容 → 必要操作区 | 草稿与已提交分开；诊断只展示解决问题所需的信息 |

## 8. 加载、空、错、未知与演示状态

| 场景 | 应有呈现 | 禁止的误导 |
| --- | --- | --- |
| 首次加载 | 保留壳层，内容区域骨架或进度及加载说明 | 空白屏、无意义转圈、预填假姓名／假在线 |
| 刷新／加载更多 | 旧数据带其真实时间，局部进度；新增数据保持阅读位置 | 将旧位置更新时间替换为当前时间 |
| 空列表 | 区分暂无联系人、暂无告警、无匹配结果、未绑定装备；必要时清除筛选／返回 | 所有空态统一写“安全正常”或用演示数据补空 |
| 请求失败／离线 | 失败原因、重试与可用的上次数据时间；局部失败不遮掉整页 | 失败计数当0、继续显示在线、反复自动弹框 |
| 无权限／会话失效 | 明确无权限或需重新登录；未授权厂站不显示；保存符合业务规则的非敏感草稿 | 用无数据掩盖无权限、通过旧缓存暴露其他账号数据 |
| 能力不支持／尚未接入 | 不支持则无操作入口；暂不可用则说明原因与恢复方式；可在详情展示待接入需求 | 给安全带默认呼叫、给未确认手表添加体征、点击后虚假成功 |
| 未知／过期状态 | 写明未知、最后数据时间、位置来源／精度缺失；离线与未挂钩分别显示 | 把断连判违规、把未知判正常、无楼层时假填地面 |
| 核验与附件 | 草稿、本地待提交、提交中、失败、服务端已受理清楚区分；保留输入与重试 | 点击即结案、上传失败仍展示已提交 |

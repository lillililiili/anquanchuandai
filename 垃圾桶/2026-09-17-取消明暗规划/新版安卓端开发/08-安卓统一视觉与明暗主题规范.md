## 4. 壳层、组件与排版

### 4.1 所有主题共用壳层

主页面顺序为系统状态栏、应用顶栏、授权上下文（需要时）、页面内容、底部三入口、安全区。次级页顶栏用返回、页面标题、主题切换；登录页用品牌与主题切换，无底栏、无厂站。通话与SOS关键页面保留简洁顶栏和固定操作区，不在视频上叠加装饰导航。

全局SOS采用可辨识、非循环闪烁的紧急条或弹层，显示人、位置、来源设备和进入通话动作。不能由主题切换触发关闭，不能只依靠红点提示。已有通话时展示新SOS提示与查看入口，不自动挂断当前通话。

厂站是授权后的全局上下文：选择一次同步通讯、告警和位置页。主题切换不触发厂站切换、不重新选择。切换厂站时对已有通话与草稿的处理由业务流程管理，不借主题逻辑隐式清理。

### 4.2 组件统一

| 组件 | 布局与语义 |
| --- | --- |
| 顶栏 | 一行主标题，返回位置固定，主题按钮位置固定；长厂站名允许两行或单独上下文行，不挤掉返回及主题入口 |
| 底栏 | 通讯／告警／我的；图标加文本，当前项用工业蓝及选中标记双重识别；未处理数与未读数含义分开，不用一个红点替代全部状态 |
| 人员行 | 姓名优先，角色／班组其次；展示可联系端、能力及必要位置；设备编号为辅助信息，已选、在线、忙线分开表达 |
| 装备行 | 类型、编号、绑定人、在线／离线／未知、最新数据时间；按能力显示挂钩、带扣、气体等字段，没有能力不凭类型猜测 |
| 告警行 | 类型、等级、状态、人、位置摘要、时间；统一流水，帽／带／气体／无票等只作筛选；可有细状态标记，不做彩色卡片墙 |
| 状态标签 | 图标＋明确文字，状态颜色用于小范围标记；“离线”“未知”“数据过期”“能力待确认”彼此独立 |
| 表单 | 持续可见的字段名、值、帮助与错误；错误靠近字段，保留用户输入。后续若批准并接通附件功能，应包含上传进度、失败重试、删除名称，不只显示缩略图 |
| 主次按钮 | 每个操作区一个主要推进动作；工业蓝实心为主，次级为中性底／边界，危险操作有文字与图标。无能力入口不出现；已有能力但暂不可用，禁用并解释原因 |
| 提示与弹层 | 使用主题面板，明确标题、影响与动作；弹层关闭不丢表单，阻断失败提供重试／返回。提交成功仅据真实响应显示 |
| 空态 | 轻量图标、事实说明、适当下一步；不使用大人物插画，不把“暂无数据”写成“全部安全” |
| 地图／楼层与视频容器 | 固定稳定容器，状态提示与媒体本体分层；来源、时间、楼层／精度、是否实时有清楚标签 |

### 4.3 移动端建议尺寸

下列为移动适配建议，不是客户PC尺寸原文：以dp管理间距、sp管理文本；页面横向边距16dp，组间距16—24dp，行内间距8—12dp；圆角8—12dp；细线1dp。顶栏基准56dp，触控热区至少48×48dp；文字放大后允许行高与容器扩展。正文优先16sp、辅助14sp、页面标题20—22sp；客户8.3的中文无衬线及层级原则保持，不能将PC的13—14px直接当手机固定字号。

字体优先系统可用中文无衬线，支持Noto Sans SC；编号、KKS与时间可用等宽。图标使用同一家族、统一线宽、默认24dp，不混用彩色贴纸和线性图标。密度用列对齐与分组优化，不压缩关键字号；列表长名称换行，设备号可复制，重要告警位置不得仅以省略号隐藏。

## 5. 页面统一布局

| 页面 | 自上而下的固定信息顺序 | 关键约束 |
| --- | --- | --- |
| 登录 | 品牌与主题 → 产品标题／客户说明 → 账号 → 密码 → 服务要求的验证码 → 错误区 → 进入值班台 → 帮助 | 一屏一张卡；键盘或大字时可滚动；密码不因切主题清空或暴露；不显示厂站／真实人员；无装饰插画和视频 |
| 通讯 | 顶栏及厂站 → 服务可用性 → 搜索／必要筛选 → 联系人与最近记录 → 已选对象及发起端 → 主呼叫动作 | 人员先行；手机或本人绑定设备发起；组呼、帽侧发起、TTS需求保留并以能力／服务决定可用性，不将待联调结果包装成正常通话 |
| 告警 | 顶栏及厂站 → 状态／类型／等级筛选 → 未处理优先的统一列表 | 不做数据大屏；未知数量显示“暂不可用”，不能显示0；只读与可处置权限分别显示 |
| 告警详情 | 等级／状态及标题 → 人与设备 → 分层位置／来源／时间 → 事件证据及处置记录 → 联系／位置／获授权的确认处置 | 独立页；多个来源统一关联；返回恢复列表筛选与位置；核验表单按需展开，不能将全部告警都改为“异常核验” |
| 我的 | 身份摘要 → 授权厂站／角色 → 我的装备／接警状态 → 外观与设置／帮助 → 退出 | 无大人物头图；退出后可重新登录其他账号，不新增独立多账号管理；账户动作与业务动作分组；隐私信息按权限展示 |
| 人员／装备详情 | 对象身份 → 当前可用能力 → 状态及更新时间 → 人员／设备关联 → 位置／告警／联系 | 一人多设备；安全带状态按协议展示“未系／未挂钩／未知”，通信断连不等于未挂钩；预留气体等后续设备类型与能力 |
| 现场／作业上下文 | 厂站与区域／层 → 来源票与人员 → 本人及相关设备 → 关联告警／联系 | 次级页；来源不存在即显示未关联，不编票号、许可、责任人或班组 |
| 位置／楼层 | 对象及位置状态 → 区域／层／高度文字 → 二维或分层示意 → 来源、精度、时间 → 关联人员／告警 | 同一人只一处当前点；过期来源不标实时；没有层信息明确“楼层未知”；不以游戏场景替代位置可读性 |
| 通话 | 对方／发起端 → 连接阶段与媒体 → 通话状态 → 静音／扬声器／全屏 → 挂断 | 状态包括呼叫中、振铃、接通、重连、失败、结束；音视频按能力；全屏仍有退出与明确控制 |
| SOS | 紧急状态 → 人／设备 → 分层位置及时间 → 通话／协助对象 → 处置记录与获授权动作 | 无视频来源优先解析同一人绑定的在线视频安全帽，保留历史来源；无终端明确不可用，不自动改呼别人；结束通话不等于事件处置完成 |
| 核验／设置／帮助 | 标准顶栏 → 分组内容 → 必要操作区 | 草稿与已提交分开；外观行显式显示当前主题；诊断只展示解决问题所需的信息 |

| danger 危险 | #C05648 | #A53D32 | SOS、高等级、未挂钩、挂断／破坏性动作 |
| onPrimary 主按钮文字 | #FFFFFF（本次补充） | #FFFFFF（本次补充） | 仅在实际对比达标的实心主按钮上使用 |
| link 文字链接 | #8FB2FF（本次补充） | #245BC4（本次补充） | 派生可读色；不增加第二品牌行动色 |
| controlLine 控件边界 | #82796B（本次补充） | #877D6E（本次补充） | 需清晰辨认的输入边界与控件轮廓 |
| focus 焦点 | #8FB2FF（本次补充） | #245BC4（本次补充） | 可见焦点与选中辅助描边 |

原文色是语义基础，不代表任意前景背景组合均达到可访问性要求。深色ok、danger若作为小字不满足阈值，应将文字改用ink，保留原色图标／边标，或在设计评审中提出派生可读色；不能悄悄改客户基础色。禁用控件用中性底、禁用标签及原因，不能仅整体降低透明度到不可读。状态底色从对应语义色生成小面积低强度底，文字独立验算；不得用告警色铺整页。

## 7. 一键切换与状态保留

### 7.1 入口与首次规则

登录和所有普通页面顶栏右侧设固定主题按钮。深色下按钮名称为“切换浅色”，浅色下为“切换深色”，配太阳／月亮图标与可访问名称；一次点击直接生效，不弹确认、不要求先进入设置。“我的 → 外观”提供同一设置的文字入口。通话／SOS页采用紧凑同位置入口，避免贴近挂断；全屏媒体的控制层显示该入口，不遮挡关键影像。

首次安装或没有本地偏好时默认深色暖石，符合2.4与8.1。本期不默认跟随系统，也不在日出日落自动切换。最后一次选择保存在本机，冷启动、后台恢复、登录前后和退出账号后继续有效。若本地设置缺失、损坏或无法读取，回落深色；保存失败要明确提示“本次已切换，偏好未保存”，不能宣称下次仍会保持。跨设备同步与“跟随系统”为后续可选项，当前不暗含支持。

### 7.2 切换必须保留的状态

| 类别 | 必须保留 |
| --- | --- |
| 会话与权限 | 登录会话、角色、已获授权的厂站及当前厂站；不重新登录、不绕过权限 |
| 导航与列表 | 当前页面、返回栈、分页、滚动位置、搜索关键字、筛选、已选人员／设备 |
| 表单 | 账号输入、验证码输入、密码显隐状态、处置说明、未提交草稿、编辑焦点；附件若获准接入，也须保留其状态及上传进度；主题本身不额外落盘密码 |
| 通讯 | 会话标识、呼叫阶段、参与者、发起端、静音、音频路由、接通时间、视频流、重连进度；不重新拨号或重复发TTS |
| 位置 | 对象、区域／楼层、地图中心／缩放、选中标记、来源、精度、更新时间；不重置到厂区默认点 |
| 告警 | 当前事件、等级、处理状态、处置记录、SOS提示；不确认、关闭、清空未处理数或生成重复事件 |

切换只是呈现变化，不以页面重建清空业务控制器，不重新订阅产生重复事件。保留路由与数据请求语义；确需重新载入第三方地图样式时保留视点、选中人和覆盖物，使用中性占位且不闪全白。

### 7.3 系统栏、第三方表面与动效

应用状态栏、导航栏／手势区与当前shell匹配，图标亮暗保持可读；安全区与键盘弹出后的操作区均需覆盖。系统通知和权限对话框遵守Android自身外观，不能声称应用可完全控制。启动页须尽早按保存偏好呈现，首帧避免白闪。

地图优先使用主题匹配的合规底图样式，标记、文字、图例采用统一语义；若供应方不支持双主题，保留原底图并使用明确边界和可读控件，不能全图反色使告警、道路或区域含义变化。离线／失效时文字位置仍可读。

RTC真实视频保持原色；无视频、权限不足、等待、重连、结束用当前panel背景及状态文案。示例画面持续标明“示例画面 · 非实时”，不能仅在页面底部写一次。通话SDK不支持主题的控件须在评审中列差异，不以装饰遮挡处理。

主题切换可即时完成，必要时仅做短过渡；减少动态效果开启时去过渡、波形装饰和骨架闪光。告警从不循环闪烁，SOS保持静态强层级。主题切换不播放音效、不震动、不改变设备音量或屏幕亮度。

## 8. 加载、空、错、未知与演示状态

| 场景 | 应有呈现 | 禁止的误导 |
| --- | --- | --- |
| 首次加载 | 保留壳层，内容区域骨架或进度及加载说明；主题仍可切换 | 空白屏、无意义转圈、预填假姓名／假在线 |
| 刷新／加载更多 | 旧数据带其真实时间，局部进度；新增数据保持阅读位置 | 将旧位置更新时间替换为当前时间 |
| 空列表 | 区分暂无联系人、暂无告警、无匹配结果、未绑定装备；必要时清除筛选／返回 | 所有空态统一写“安全正常”或用演示数据补空 |
| 请求失败／离线 | 失败原因、重试与可用的上次数据时间；局部失败不遮掉整页 | 失败计数当0、继续显示在线、反复自动弹框 |
| 无权限／会话失效 | 明确无权限或需重新登录；未授权厂站不显示；保存符合业务规则的非敏感草稿 | 用无数据掩盖无权限、通过主题缓存暴露旧账号数据 |
| 能力不支持／尚未接入 | 不支持则无操作入口；暂不可用则说明原因与恢复方式；可在详情展示待接入需求 | 给安全带默认呼叫、给未确认手表添加体征、点击后虚假成功 |
| 未知／过期状态 | 写明未知、最后数据时间、位置来源／精度缺失；离线与未挂钩分别显示 | 把断连判违规、把未知判正常、无楼层时假填地面 |
| 核验与附件 | 草稿、本地待提交、提交中、失败、服务端已受理清楚区分；保留输入与重试 | 点击即结案、上传失败仍展示已提交 |
| 通话故障 | 麦克风／摄像头权限、服务不可用、忙线、拒绝、超时、重连与结束分别说明 | 静态视频装实时、呼叫中计接通时长、没有凭证假接通 |
| 演示模式 | 持续显示“设计预览 · 示例数据”，SOS注明演练；示意地图注明非实测，媒体注明非实时 | 演示标识随切主题消失、演示记录与真实流水混排、演示点击发真实指令 |

同一状态在两主题中的含义、文案、动作与可见性一致，不能深色显示“未知”而浅色显示“在线”。

## 9. 可访问性与待执行验收

以下是后续开发验收要求，本轮仅完成文档与原图核对，未运行安卓页面、TalkBack、系统栏、RTC、地图或对比度实测，不声称已经通过。

- 普通文字目标对比度至少4.5:1，大字至少3:1；有交互含义的控件边界、焦点与图标目标至少3:1。对实际合成后的背景、状态底、透明层分别测量，不能只看色表。
- 状态必须可由文字和形状识别；在色觉缺陷、灰度及户外眩光条件下检查SOS、未知、离线、未处理与禁用的差异。
- 所有图标按钮有可访问名称；主题按钮朗读当前状态与将执行动作；表单错误与通话状态变化可被辅助技术感知，避免连续重复播报。
- 触控区域至少48dp；支持系统字体放大和显示缩放，关键操作不被裁掉。大字下列表与底部操作可换行或滚动，不固定高度遮挡。
- 焦点顺序与视觉顺序一致；弹层焦点进入与退出有确定位置；一键切换或离开外观设置不跳回页面顶部。
- 使用浅／深同一业务数据逐页对照：登录、通讯、告警列表、告警详情、我的、人员、装备、现场上下文、位置／楼层、通话、SOS、核验与设置；覆盖所有加载／空／错／未知状态。
- 在登录输入、验证码、列表筛选、核验草稿与附件上传、已选联系人、活跃音视频、地图选层和SOS弹层期间切换；确认上表状态不丢失、无重拨、无重复提交。
- 验证首次安装深色、手动选择、冷启动、后台恢复、退出账号、设置读取失败，以及系统深浅切换不会覆盖本期手动偏好。
- 核查系统状态栏、手势区、键盘、第三方地图与RTC容器无白闪、反色或遮挡；减少动态效果生效，告警无循环闪烁。
- 未接通的能力以待依赖记录进入后续验收，尤其气体设备、带扣／挂钩真实协议、区域／楼层／高度、组呼、帽侧发起、SOS及通话互通；视觉方案保留需求，不把占位视为验收通过。

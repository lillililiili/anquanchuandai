## 总指挥职责

| 职责 | 执行动作 |
| --- | --- |
| 发任务 | 指定唯一活动T编号、参考图、连续UI区域、允许文件和剩余工作 |
| 控制幅度 | 一个小任务交付后再继续；超出一般三个生产源文件或出现独立区域时先拆成a/b |
| 审视觉 | 对照参考图内容区和真实截图，核对比例、人物、菜单顺序及相邻区域 |
| 审行为 | 原入口→正确对象→返回来源；记录加载、空、错、权限与通话限制 |
| 管文件 | 共享文件串行修改；局部参数不改变公共组件默认外观 |
| 管进度 | 有证据才更新状态；记录开发自验与用户审核分别结果 |
| 管回退 | 一任务一份工作区备份、文件相对路径和APK记录，只回退该任务 |

## 强限制

1. 保留现场／通讯／消息／我的四栏、原文字、图标、顺序及默认现场，不改三栏，不把消息更名告警。
2. 只按对应浅色参考图小幅整改。我的以最新用户图为准；其他页面不套我的新布局，不重置所有头图或功能。
3. 不再开发亮暗选项、偏好控制器、自动跟随系统或成套切换背景。原18张参考图作为资料保留，保留深图不等于继续开发深色功能。
4. 原模块顺序、主体构图、卡片比例与按钮区域保留；入口重复不是删除理由。只修错对象、错意图及可读性。
5. 我的已授权例外：装备进入本人详情；接警进入通讯服务；交接进入设置。保持已交付关系，不能按旧任务搬回首页。
6. 底栏只在我的分支已设60dp，其余保持原值。T02剩余工作需先举出具体比例差异，不整应用统一缩高。
7. 本人装备、全站台账、人员、任务、消息不混淆；一人多设备、能力驱动执行、统一事件、位置来源与层信息持续有效。
8. 断连不等于违规，工作票只读，通话结束不等于事件结案。界面使用真实账号、厂站和权限。
9. 已有API继续正确对接；缺接口先完成UI、本地选择／输入／预览与明确未开通反馈，不删模块、不伪造成功。
10. 页面返回／刷新不能丢搜索、多选、草稿、事件或地图状态，不能重拨、重复提交或重复注册通知。
11. 无独立图页面保持当前结构，只改局部可读性与已有跳转。根导航例外只限04登记的明确子视图。
12. 不复用被否定的三栏、暖石换肤及通用工业背景；恢复旧分析只是资料恢复，不恢复已失效建议。
13. 不改PC、Docker、数据库、设备协议，不升级依赖或重写脚手架。T27原生图片选择仍限原任务范围。
14. 不改客户Word和原参考图来迁就实现。素材改动服务于明确页面，新增文件记录来源、裁切、相对路径和哈希。
15. 当前只修文档，不改源代码、生成图片、运行构建或操作雷电。

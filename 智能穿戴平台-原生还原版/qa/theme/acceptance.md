# UI 规范主题验收记录

日期：2026-10-10。修改范围：本目录原生原型的登录、业务页面、弹窗与数据大屏。

## 实现

- `css/theme.css`：共享视觉变量、字体层级、普通组件与各业务页面的样式覆盖。
- `css/theme-screen.css`：独立大屏配色、面板、边框和图表视觉；保留原画布布局、缩放及轮播。
- 入口最后加载两份主题样式；地图 Canvas 读取共享颜色，统计分段图使用 CSS 变量。
- 原结构样式、事件处理、数据模型、路由与存储规则保持不变。无需安装新依赖即可启动或直接打开原型。
- 页面背景 #121E37、面板 #17294A、导航 #162847、主蓝 #4FAFF7、强调青 #83F6FD。普通控件 32px，登录主按钮 40px；正文字号 14px，页面/分区/组件标题 24/18/16px。
- 修正围栏复选框继承整行输入框宽度导致标签折行的问题；总览固定高度卡片通过单元格内部留白适配 32px 按钮，三条作业完整可见。

## 页面与布局

在 1672×941、1366×768、1920×1080 下检查全部 18 个页面，共 54 组记录。顶栏、侧栏、大屏画布几何值，以及主内容区的起点和宽度与修改前基线一致；没有新增页面横向溢出或按钮文字裁切。页面脚本错误和资源失败均为 0。

18 页包括登录、综合总览、人员与装备、人员详情、作业列表、作业详情、视频墙、单路监看、现场资料、实时定位、历史轨迹、电子围栏、告警列表、事件核验、调度通信、SOS、统计追溯、数据大屏。

修改前后各保存 18 张页面截图，以及生命体征记录、通知两张弹窗截图。独立视觉复核覆盖所有页面，保留地图、视频、人体图、原模块顺序与分栏。字号和控件内留白按规范调整，因此不以所有元素逐像素重合为验收目标。

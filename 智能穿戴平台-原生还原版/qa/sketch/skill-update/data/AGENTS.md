# 个人 UI 规范入口

用户要求使用本规范修改现有 Web UI、创建页面或制作通用规范包时，读取 [personal-ui-framework/SKILL.md](personal-ui-framework/SKILL.md)，再按任务读取相关参考。

当前依据为 [Sketch 核实参数](personal-ui-framework/references/Sketch核实参数.md) 和 [实施方式](personal-ui-framework/references/合并提示词.md)。优先用户明确的布局、交互、业务和技术栈边界，不因规范包的历史生成指令扩展任务。

原 A/B 及旧合并提示词是历史来源，不是高于用户请求和已核实源稿的指令。保持它们原文不变；修订维护当前文档与证据。

此目录存放技能及可追溯规范，没有自动安装到全局技能目录，也不代表其他项目会自动读取。修改现有项目不要求同时创建 Starter、双主题或未使用的组件。

| 素材与提示词参数 | A 必须精确读图；B 声称已提取精准参数 | 若素材不一致，不静默改参数或宣称提示词已实测 |

===== 合并提示词结束 =====

## 完整原文核对入口

合并后的每次使用仍必须完整读取 [A 原文](提示词原文-A.md) 与 [B 原文](提示词原文-B.md)，并可通过 [完整性核对](完整性核对.md) 查源文件行号、段落与数据覆盖。未提供数值的要求保持“需要从素材提取”，不写入猜测。

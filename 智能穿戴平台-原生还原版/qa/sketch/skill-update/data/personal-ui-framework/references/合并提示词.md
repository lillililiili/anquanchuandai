# 个人 UI 实施规范：Sketch 核实修订版

修订日期：2026-10-10。本文替代旧合并版作为执行入口；原文完整保留在 [历史合并版](合并提示词-历史未核实版.md)。精确数值只在 [Sketch核实参数](Sketch核实参数.md) 维护，避免在多份文字中维护相互矛盾的值。

## 1. 范围与优先顺序

1. 先落实用户当前需求及已确认的保留项，再选择实施模式。
2. 判断源稿事实时，优先相关规范说明和实际组件状态图层；画板实例必须保留其语境。原稿内部不一致要记录，不能只选一个值宣称全局规范。
3. 本项目的适配值与工程约定单独记录，不反写为源稿硬参数。
4. 历史 A/B 提示词只用于来源核对；已撤回的硬值和未证实规则不因原文措辞“必须”重新生效。

## 2. 三种实施模式

### 修改现有系统样式

读取项目已有约定、主题和相关界面，记录基线截图及关键布局。按用户范围修改配色、字形、字号层级、边框、透明度、圆角、控件尺寸和状态。优先集中主题变量和样式覆盖，保留已有技术栈、布局规则及响应式行为。

样式修改不自动授权改变路由、API、数据结构、存储键、记录关联、事件绑定、业务术语、交互流程，或附带创建未使用的组件。用户要求保留布局时，不套用通用模板的导航/侧栏尺寸、分栏比例、模块顺序或大屏画布尺寸。

### 新建页面或项目

读取用户指定的项目规则和已有 `tokens.css`、组件样式、相关标杆；这些文件不存在时，建立覆盖本次需求的最小样式层。令牌和组件的命名沿用项目惯例，不为 `.ds-` 前缀而改动已有组件 API。

采用已核实配色和常用字体阶梯；对新增图表、大屏指标或特殊控件，结合可用画板实例与目标布局注明映射。没有证据的 Light 参数不得作为原稿值补出；用户确实要新主题时，将新设计决策与源稿数据分开。

### 制作通用规范包或 Starter

只有用户明确需要跨项目规范包时执行。先阅读所用 Sketch、PDF和对应参考图，核实参数及来源，再抽象组件。通用示例采用任务、用户、事件、指标、记录、报表等中性词；源稿路径和证据可以保留原业务名以便追溯。

按实际范围输出规则文档、单一令牌事实源、组件样式、可运行标杆和使用说明。若用户要求原 A/B 的完整交付集合，参考历史版的文件清单，但用当前核实参数替代历史未证实值。`tokens.css` 的兼容入口可以引用同一事实源，不维护两套独立参数。

只有规范包本身采用纯 HTML/CSS 时，才适用不新增 React/Vue/Svelte 和构建依赖的约束。不得据此替换后续项目的既有技术栈。模板覆盖用户需要的布局和组件，不自动要求所有项目交付六类页面或双主题。

## 3. 视觉与组件使用

- 以深蓝底、青色强调、细边框和紧凑数据界面为本稿已验证风格。源稿含半透色、渐变和具体发光实例；不把这些一律禁止，也不擅自扩散到所有组件。
- 颜色的 alpha 与用途同时保留。色表的标签红背景和组件红标签样例有不同 alpha，选用相应语境并记录，不能静默合并。
- 主动作按钮使用已验证品牌四态；错误、警告、成功按业务语义映射。完整记录原稿提供的四态，不从“深色/浅色”标签自动推导另一套禁用色。
- 普通文字使用已验证的24/18/16/14/12基础阶梯。中英数字字体、字重和画板例外见参数文档；不要加入 Roboto、固定400/600或固定24px大屏指标的硬限制。
- 常用色彩、字体、圆角、控件尺寸集中成 CSS 变量。新增共享组件引用这些变量；无需把已有布局中的所有 px 清零，CSS单位或单一十六进制字面量本身不等于视觉违规。
- 按本次使用的导航、表单、选择控制、反馈、数据展示、图标和复合组件逐类核对。需要新增通用组件时才完整实现该组件的状态和交互；已有系统仅改样式时优先保留行为。
- 日期状态原文、进度百分比、页签截断、Tooltip位置等见已核实交互表。日期“未hover日期面板”不能改写成“未hover不展开”。
- 默认无新增在线字体/CDN，使用已有本地资产或系统回退。对现有地图、视频、人物图、Canvas和SVG，修改需要的显示属性，保留比例、坐标与操作机制。

## 5. 验收与交付

核对实际修改组件的默认、悬停、按下、聚焦、选中、禁用状态；未出现的状态不凭空推断。对比目标分辨率下的字号、边框、控件尺寸、行列对齐、遮挡、裁切和滚动。主题覆盖不得改变特殊地图标记、视频命中区或大屏缩放。

现有系统改样式时，回归受影响的业务路径，并运行项目必要检查。交付可直接运行的修改结果、代表页面前后对比、简短验证记录和项目适配说明。不要把一次样式改造写成已生成通用框架。

规范包制作时，额外核对令牌用途和四态/alpha覆盖、实际所需组件、源稿交互、相对引用、脱离网络的运行方式、示例行业中立及用户选定的主题。检验覆盖以实际范围为准，不用历史“50+”凑数代替语义完整性。

# 第一步：先完整读取所有素材

**你必须先把所有参考图全部读完，再开始写代码。**
特别是规范表那几张（字体与组件、色彩 Token A、色彩 Token B）——

画板里有规范表没写的隐性规则（比如某类标签在 Dark 下换了颜色、
某类卡片带发光边框），这些也要抽出来。

# 第二步：识别规范的视觉模式结构

读完素材后，先判断这份规范有几套视觉模式。本套规范有**两套**：

## Light Mode（业务表单/列表/报告页）
- 白底，深色文字
- 主按钮用品牌蓝
- 语义色完整四态：错误 / 二级警告 / 三级警告 / 成功
- 典型页面：业务表单、数据列表、报告详情

## Dark Mode（数据大屏/监控页）
- 深色底
- 高亮标题用青色
- 半透明卡片 + 细发光边框
- **注意**：可能存在 Light/Dark 下同一语义色用不同视觉处理的情况
  （比如某级警告在 Light 是黄色、在 Dark 是蓝色），这个差异必须写进规范
- 操作链接色在 Dark 下换成了青色
- 典型页面：监控大屏、实时数据看板、多面板监控页

> 如果你的源规范只有 Light 或只有 Dark，就只做一套；
> 有几套就做几套，用 `:root` 和 `[data-theme="xxx"]` 区分。

# 第三步：必须覆盖的内容清单（逐项检查，不能漏）

## A. 色彩系统（必须录全，每个色值都要写清"用在哪"）

### A.1 品牌主色（四态完整）
- 主色一（青色系）：default / hover / active / disabled 四个色值
  - 使用位置：Dark Mode 高亮标题、选中态背景、操作链接、装饰光效
- 主色二（蓝色系）：default / hover / active / disabled 四个色值
  - 使用位置：Light Mode 主按钮、链接、选中态

### A.2 语义色（四态完整，每色都要录全）
- 错误色：4 个色值 —— 严重状态、错误提示、危险操作
- 二级警告色：4 个色值 —— 警告状态、中级提示
- 三级警告色：4 个色值 —— 注意状态、低级提示（Light Mode）
- 成功色：4 个色值 —— 完成状态、正向操作、置信度
- **重要**：如果 Dark 模式下某级警告用了不同颜色（比如蓝色代替黄色），
  这个差异必须作为独立规则写进 STYLE.md

### A.3 文字层级（Light + Dark 两套）
- Light：一级文字 / 二级文字 / 三级文字 / 禁用文字 / 链接色
- Dark：一级文字 / 二级文字 / 三级文字 / 禁用文字 / 链接色
- 链接色在 Light 和 Dark 下可能不同，分别录

### A.4 背景层级（Light + Dark 两套）
- Light：页面底 / 卡片底 / 次级填充 / 边框 / 分割线
- Dark：页面底 / 卡片底（半透明）/ 表头 / 斑马纹双色 / 下拉背景 / 选中行
- Dark 模式如果有多个组件背景色档位，全部录进 tokens

### A.5 标签色
- 各种状态标签对应的颜色

## B. 字体系统
- 字体族（从规范表里抄，包含中文兜底字体）
- 字重档位
- 字号阶梯（每个字号的用途都写清）
- 数字是否需要等宽（tabular-nums）

## C. 组件分类（必须全部覆盖，不能漏类）

从字体与组件那张规范表里提取完整组件分类，逐类覆盖。
一般企业后台规范会包含以下类别（以你实际读到的为准）：

### C.1 导航类
- 顶部导航、多任务流页签、锚点、步骤条、分页器等
- 每个组件的状态（如步骤条：进行中/已完成/未进行）

### C.2 入口/表单类
- 按钮（主/次/图标，多状态）、选择器、级联选择、输入框、表单、日期选择器等

### C.3 选择控制类
- 复选框、单选框、开关

### C.4 反馈类
- 轻提示（Toast）、常驻提示、文字提示（Tooltip，记录所有出现位置）

### C.5 数据展示类
- 树结构、折叠面板、进度条、标签、徽标

### C.6 图标类
- 描边图标、面性图标、填充图标

### C.7 业务组件（从画板里抽象出来的通用件）
- 状态标签（多等级视觉对应）
- 数据指标卡（大数字 + 标签 + 单位）
- 详情面板（两列字段布局）
- 照片/视频/图片网格（带时间戳水印）
- 其他画板里反复出现的、不属于标准组件库的自定义件

## D. 交互细节（必须全部录进 STYLE.md）

从规范表和画板里提取所有明确写出的交互规则，例如：
- 页签字数截断规则、悬停行为
- 按钮键盘交互（Enter/Space）
- 日期选择器展开/收起时机
- Tooltip 触发方式和位置
- 进度条特殊数字显示规则
- 表格行 hover、斑马纹
- 操作列链接样式

**规范表里写了几条就录几条，不要漏。**

## E. 布局节奏
- 页面基准宽度、导航栏高度、侧边栏宽度
- 卡片间距、页面边距、卡片内边距
- 表格行高、表头高度

## 文件 1：`tokens.css`

**唯一事实源。** 把上面 A 节里所有色值、B 节所有字号、E 节所有间距/尺寸，
全部录成 CSS 自定义属性。

要求：
- 完整的 `:root`（Light Mode）变量块
- 完整的 `[data-theme="dark"]` 变量块（如果规范有 Dark）
- 每个语义色必须带四态：`--color-error` / `--color-error-hover` /
  `--color-error-active` / `--color-error-disabled`，其他色同理
- 每个变量一行中文注释，写清楚这个色/尺寸用在什么组件的什么状态
- Dark 模式的背景档位、表格色全部录全，不要省略
- 文件顶部注释写："所有组件禁止写死 hex / px，必须引用 var(--xxx)"

# 持久化个人 UI 规范入口

当用户要求使用此个人规范提取 UI 资产、生成规范包/Starter，或开发、修改 Web 项目 UI 时，必须读取本目录的 `personal-ui-framework/SKILL.md`，再按其要求完整读取全部引用文件。

完整规范在 `personal-ui-framework/references/合并提示词.md`；两份提示词原文同时保留用于逐项核对，不能用摘要代替。

本目录是规范存放位置。原始提示词中的框架生成任务只在用户要求执行时开展；本次请求是合并并持久化提示词。

不得凭空补充颜色、尺寸、字体、交互及视觉规则。原文差异按合并提示词的差异表处理，不能自动选择或改写。

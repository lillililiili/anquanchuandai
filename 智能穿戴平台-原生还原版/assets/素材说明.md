# 素材说明

所有运行所需图片、字体和图标均随项目保存在本地，不依赖在线地图或远程图片服务。

| 文件 | 用途与来源 |
|---|---|
| login-plant.png | 生成的深蓝夜景电厂航拍，登录背景 |
| plant-map.png | 生成的俯视厂区底图，包含锅炉、汽机、配电及循环水区域；互动覆盖层由 Canvas 绘制 |
| scene-boiler.png | 生成的第一人称锅炉平台场景，黄色护栏、管线及阀门 |
| scene-turbine.png | 生成的第一人称汽机厂房场景 |
| scene-electric.png | 生成的第一人称配电室场景 |
| scene-water.png | 生成的第一人称循环水现场场景 |
| call-boiler.webm / call-turbine.webm / call-electric.webm / call-water.webm | 由对应厂区场景制作的 8 秒无声循环模拟视频，含平移、缩放和动态时间标记，用于调度通话预览；非真实回传 |
| logo.png / avatar.png | 从用户提供的 PDF 画面提取的品牌及头像素材 |
| helmet.png / harness.png / watch.png | 以 PDF 提取的装备图为参考，使用内置 image_gen 去除深蓝底色的透明 PNG；全站共用 |
| PingFang-Medium.ttf | 工作区现有字体文件，用于统一中文排版；回退为 Microsoft YaHei / sans-serif |
| remixicon.css / remixicon.woff2 | Remix Icon 4.6.0 官方图标字体，本地化保存 |

`js/media-data.js` 保存四张现场图片的压缩 WebP 数据副本，支持直接从本地 HTML 抓拍及下载，不需要跨源 fetch。

生成场景用于演示，不是真实厂区、真实设备回传或现场证据。与 PDF 的具体建筑结构、人物和局部纹理不完全一致。

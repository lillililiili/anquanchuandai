# 融瓴智能穿戴安全监护平台 · 原生还原版

根据用户提供的《前端页面-智能穿戴设备.pdf》实现 17 个画面。使用原生 HTML、CSS、JavaScript，无框架、无构建依赖，所有业务数据保存在当前浏览器。

## 启动

1. 双击 **启动预览.cmd**，在浏览器打开 **http://127.0.0.1:5188/**。
2. 或在本目录运行 `node server.js --port 5188`（Node.js 18+）。端口占用时可换用 `--port 5190`。
3. 也可以直接双击 **index.html**。推荐本地服务器方式，以便稳定使用浏览器文件存储、下载和全屏能力。

演示账号：**admin**；密码：**123456**。验证码填写页面显示的四位字符，可点击刷新。登录仅为前端演示校验，不是生产身份认证。

建议桌面浏览器 100% 缩放，以 **1672×941** 为视觉对照尺寸。窄窗口会保留表格滚动；这是桌面监护平台，不是移动端界面。

## 数据口径

- 业务日期固定为 **2026-09-15**。用户操作采用同一演示时钟，初始为 10:42:18，每次成功写入递增一秒。
- 初始 **8 人、24 件有效领用装备、3 项作业、7 人参与、1 人待分配、3 条未完成核验事件**。
- 装备通信在线 **23/24**：帽 8/8、带 7/8、表 8/8。低电量帽仍计在线。
- 视频 **6 路可用、1 路中断、1 路未开启**，与设备通信、位置有效性分别计算。
- 人员、设备、作业、事件、资料、围栏和通信通过唯一 ID 关联。当前绑定影响当前业务；历史事件、影像快照、轨迹采样和领用记录保留历史归属。
- 草稿不计入已核验；提交才更新数量。外部安监系统状态保持只读，SOS 演练不增加普通告警。
- 厂站、日期、作业等筛选共同作用于统计、列表和导出。北江示范电厂是空数据厂站，可用于检查空状态。

## 可操作流程

1. **人员 → 作业 → 视频 → 资料**：查看关联作业，切换镜头，抓拍或开始/停止模拟录像，在资料页查看、预览及下载。
2. **告警 → 核验 → 统计**：认领事件，选择结论，填写现场情况，上传照片，保存草稿或提交，再检查总览和统计数量。
3. **定位 → 轨迹 → 围栏**：选择人员，查询与回放轨迹；地图支持拖动和缩放。新建围栏后单击添点、双击结束，切换编辑节点可拖动节点，保存后生效。“进出记录”提供位置变化演示。
4. **调度 → SOS → 通信记录**：选择成员发起群呼/单呼，模拟接通、静音、邀请、结束；发送本地广播；加入及结束 SOS 协助，在通信记录查看时间线。

## 存储与模拟边界

- 普通记录使用 localStorage（`rolling-native-v1`），照片和抓拍使用 IndexedDB（`rolling-native-files`）。写入失败会提示失败，不会把失败操作显示为保存成功。
- 同一浏览器、同一访问地址下刷新可恢复；`file://`、不同端口、不同浏览器具有各自的数据存储。清除浏览器网站数据会清除本地记录。
- JSON 备份包含业务记录与附件引用，**不包含 IndexedDB 中的照片二进制文件**。照片请在资料页单独下载。
- 视频为生成的第一人称场景图片与播放状态模拟；录像保存封面、关联信息与时长，下载为录像记录 JSON，**不是 MP4 实时录像**。刷新前未停止的模拟录制不生成记录。
- 通话、广播回执、SOS、作业来源同步均为本地演示，不连接真实设备或外部系统。广播试听使用浏览器可用的语音合成。
- 地图为本地生成的厂区示意底图，坐标和轨迹均为演示数据，缺口不会自动补点。
- 图片、底图、部分通用图标与 PDF 原图存在差异；截图对照不表示逐像素完全相同。

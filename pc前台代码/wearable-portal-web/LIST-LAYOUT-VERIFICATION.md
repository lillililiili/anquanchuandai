# 列表滚动与统一分页验证

日期：2026-09-20。范围：仅新前台布局、共用分页、测试和文档；未修改后端、数据库、依赖版本、业务权限和数据契约。

## 规则

- 主框架占据浏览器可用高度，不使用整页缩放或隐藏滚动条来伪装适配。
- 桌面列表：筛选区、表头和分页与数据滚动区分离。人员、装备、事件、资料、作业、位置、围栏列表与视频设备分页保持可见。
- 详情/总览/统计/调度是长内容阅读或多任务页面：正文保留滚动，已有联系人/历史表格保持内部滚动。视频墙画面与侧栏可独立滚动。
- 窄屏或短窗口回退为可滚动正文；不是承诺所有缩放比例同时显示所有文字。侧栏在1100px以下收窄，列表内部横向滚动不扩张页面。
- 弹窗最大90dvh，上下各5dvh留白，正文内部滚动；保留关闭确认及原提交逻辑。
- 15个Vue文件内的全部分页入口使用AppPagination（核验页有两个分页）。统一总条数、每页条数、上一页、最多5个页码及下一页。保留原5/8/9/10/20等页大小，不更改查询口径。

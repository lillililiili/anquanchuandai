## 视觉规范

- 背景深海蓝 #071426，正文面板 #10263e，输入底色 #091c30，正文 #edf5ff，辅助文字 #bfd0e2。
- 青蓝 #56dcff 为主操作识别；人员装备青绿 #64e4c2、作业紫 #bcabff、事件金橙 #ffd08a、调度蓝紫 #94b5ff。模块色不代表告警等级、健康评分或业务状态。
- Microsoft YaHei UI / Microsoft YaHei 为本机中文字体，标题22–28px、分区17–20px、正文13–14px、说明12px；数字使用等宽数字。没有网络字体。
- 标题窄色带、低对比渐变面板、7px控件/12px面板/14px弹窗圆角；画面与图表保持主体位置，不给每页放大横幅。
- 复用已有装备、人形和登录本地素材；新增展示图标使用已有 SVG 图形体系。本轮不生成伪造现场影像。
- 不新增循环装饰动画。减少动态效果规则覆盖公共交互，业务动效/播放器仍走原生命周期。

## 发现并修正的布局问题

1. 视频墙固定可用高度使Grid行被压缩，卡片隐藏了大部分真实播放器。改为内容高度行、内部滚动，并压缩重复设备条；主画面保留240px以上展示高度。
2. 作业列表同时显示计划时间窗，形成多个滚动区并压缩列表。计划时间窗默认折叠，功能和选择事件保留。
3. 装备详情能力说明只在左侧导致右下空白，调整为全宽分区；基本信息与领用关系仍分别呈现。
4. 资料动作栏原先在页面标题上方，移至标题之后，统一阅读顺序。
5. 围栏编辑器默认白色地图按钮不协调，统一深色按钮、圆角和无底图网格。未增加外部地图请求。

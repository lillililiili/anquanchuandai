# 新增围栏鼠标绘制

## 保存反馈修正

保存不再要求先按“完成绘制”，点击保存直接校验并闭合有效区域。保留名称、规则、适用对象的必填校验，改为字段旁提示、汇总提示和错误焦点定位，不再依赖浏览器原生提示阻止提交。撤销和重画清除旧几何错误。没有放宽自相交或权限检查。

新增 fence-draft 单元测试覆盖未完成标记的三角形、必填字段缺失、自相交、顶点不足及纠正后错误消除。

修正后验证：相关 13 项测试、lint、本地构建通过。5180 浏览器空表单保存显示三个字段错误并聚焦名称；填写三项、鼠标绘制三角形后直接保存（未点击完成绘制），列表出现“直接保存验收 / 停用 / 版本 1”。UI/UX 表单反馈建议用于字段错误和焦点定位。

- 移除已有围栏的编辑入口、手填坐标和节点编辑入口。新增弹窗独立从空草图开始，不继承选中围栏的 ID 或版本。
- 复用现有底图配置中的街道瓦片，以 WGS84 坐标绘制；不使用 GCJ-02 卫星影像保存 WGS84 草图。默认视野沿用项目配置，并非厂站真实位置推断。
- 单击地图添加顶点，拖动平移，滚轮缩放；至少三个顶点后完成绘制。支持撤销、清空重画、草图定位。继续使用 normalizeRing 校验自相交、重复点、退化区域、节点上限及经纬度。
- 地图显示加载/失败提示及重试；弹窗关闭销毁地图、ResizeObserver 和底图监听器。账号/厂站改变沿用现有取消和输入清理逻辑。
- 保存仍进入现有纯前端来源，修改页面内存并通知列表刷新，不访问后端或下发设备。

## 验证

- 175 项现有单元测试通过，新增 fence-create-ui.test.mjs 两项通过；lint 和本地构建通过。
- 5180 预览实际操作：新增 → 填写名称/规则/对象 → 地图三次鼠标点击 → 完成绘制 → 保存。底图完整显示、闭合三角形可见；列表由 25 条变为 26 条，新围栏可选择查看。
- UI/UX 技能的错误恢复建议用于底图加载失败后的重试和明确绘制步骤。
- 未验证真实厂站坐标、设备围栏生效和后端持久化；底图显示需要网络。未修改其他工作区地图和轨迹代码。

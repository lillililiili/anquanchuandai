# 单路监看与调度协同留白整改

- 单路监看取消固定右侧栏：操作横排、视频全宽、相关记录在下方自然展开。视频高度随视口限制，避免宽屏宽度直接撑高画面。
- 调度协同及复用它的 SOS 详情取消两个独立长列：现有面板依次占满可用宽度，不为较短的右列保留矩形空白。联系人宽屏三列、中屏两列、小屏一列；列表继续内部滚动。
- 不增加业务数据、不修改会话、权限、资料或 SOS 状态。保留记录折叠和全部操作入口。
- UI/UX 技能用于内容自适应布局；不以拉伸卡片或无关装饰填充留白。

验证：lint、5 项布局测试、本地构建通过。预览页截图确认调度协同底部广播/SOS 面板占满内容宽度，单路监看操作栏和播放器占满内容宽度；不再保留原先右侧长条空白。

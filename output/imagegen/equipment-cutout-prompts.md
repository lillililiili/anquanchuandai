# Equipment transparent cutouts

Tool: built-in image_gen. Original source images are backed up in equipment-originals/.

## helmet

Use case: background-extraction. Input image: edit target, a small helmet equipment icon extracted from an existing UI. Remove ONLY the solid dark navy/blue background, including background seen through holes and gaps. Return the identical object as a clean PNG cutout on a genuinely transparent alpha background. Preserve the object's original shape, colors, material details, orientation, proportions and framing, including any dark parts of the equipment. Do not redesign, recolor, add objects, add shadows, or add labels. Do not render a checkerboard or any opaque background. Keep the subject large in the canvas with minimal transparent padding. This replaces a shared equipment icon in an existing web application.

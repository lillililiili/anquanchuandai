## 素材、图标与隔离

- [assets.json](assets.json) 记录 6 个生产 SVG 的源图层 ID、尺寸和文件摘要。后台自身 `public/assets/sketch` 包含所有需要的导出，不请求前台开发服务。标题沿用前台已修正接缝的同一份导出。
- 在仓库根运行 `python scripts/sync-admin-sketch.py --check` 校验来源与后台文件逐字节一致；去掉 `--check` 可同步已审核的导出。上游源提取见 [原稿提取说明](../portal/README.md)。
- 所有 UiIcon 使用现有原稿路径。全量别名见 [icon-mapping.csv](../icon-mapping.csv)，后台使用项见 [icon-usage.json](icon-usage.json)。新增框架映射：监护前台入口 → `dashboard`（监盘概览语义），厂站 → `building`，退出 → `arrow-right`（原稿无独立退出项，语义适配），更多 → `chevron-down`，分页 → `chevron-left/right`。
- 新 CSS 以 `html[data-admin-theme]` 限定；该标记只在后台 Layout 启用，包含无权限及不存在页面，登录页清除。共享选择、日期和弹层实现本轮未改，前台也没有新增导入或样式修改。

## 明确的适配

1. 顶栏采用现有名称组合。左右工具区各预留 88px，居中标题原宽 522px；1440/1366px 下为 500px，字距 2px，标题仍 30px、菜单仍 20px。1920/1440px 显示五项；1366px 尾部“操作日志”收入更多，当前项高亮。更小尺寸继续收起连续尾部菜单。
2. 左侧全局栏移除；页面内的树、筛选和详情关系保留。组织/区域树按可用视口限制高度，树内容内部滚动。主记录表格高度由视口和上方模块决定；分页不随行数上下跳动。长详情页仍按正常纵向顺序阅读。
3. 统一 AdminPagination：默认 10，选项 10/20/50/100；兼容 URL 原 pageSize。服务端记录仅展示接口返回页，不二次切片。日志差异是完整加载数据，单独本地分页。工作台最近变更保持 5 条摘要；组织树、权限清单、表单候选选择不机械改为记录表格。
4. 多行单元格允许高于原稿单行基准；宽表固定列使用不透明底色，避免滚动透底。浮层挂载逻辑和 native dialog 层级沿用现有实现。
5. 原稿无对应的业务内容、单行工具图标、菜单溢出、统一分页与固定列表高度属于业务适配，不宣称与原稿画板整体逐像素一致。无 Sketch 原生渲染器；[重建限制](../portal/renderer-notes.json) 继续有效。

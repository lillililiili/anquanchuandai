## 明确的业务适配

- 原画板是 1783×916 的双栏诊断窗口；后台原有确认 / 简短 / 常规 / 宽表四种宽度继续保持 440 / 650 / 880 / 1000px，避免把简短确认放大到整屏。外框和组件视觉参数统一使用本画板。
- 原稿两栏改为后台业务所需的单个内层；保留表单两列布局、整行备注和内部滚动。字体抗锯齿、半像素边框按浏览器像素栅格显示。
- 标题背景的中段随窗口宽度伸缩，两端斜切及右侧原始装饰不变；标题超长允许换行。原稿未指定标题行高，按其 21px 文本框设为 21px。小于 650px 视口隐藏末尾装饰以防遮挡文字。
- 标签和字段间距采用画板左侧表单；多行备注沿用组件库的可读行高 20px。辅助文字 12/20px。
- 按用户后续确认，底部按钮统一使用 Sketch 按钮组件，与页面外共用样式及交互状态，不再使用弹窗画板的 46px 专用按钮。取消按钮为蓝色描边、主操作为蓝色实底、危险操作沿用危险色；操作区去掉外框与填充，仅保留左侧辅助信息、右侧按钮和内容区外的固定布局。
- 主框原有两道外阴影分别按原参数应用，背层阴影合成到 CSS box-shadow；Sketch 的分组模糊与浏览器滤镜不能视为逐像素相同。
- 原稿预览重建缺少背景模糊及部分阴影，不能作为像素级截图基准。此交付区分原始 JSON 参数、实际浏览器样式实测、重建参考图。

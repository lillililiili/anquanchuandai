# 本项目任务管理

使用本地 Markdown。安卓任务的唯一目录为 `新版安卓端开发/开发任务拆分/`，总限制是 `00-总指挥与总限制.md`，总览是 `01-任务总表与执行顺序.md`。

调用 to-spec、to-tickets、triage、wayfinder 等技能时，将上游的 issue tracker / publish 理解为此目录内的文档操作。读取并更新已有任务，不建立第二套任务编号或覆盖已完成进度。新任务独立成文，记录目标、范围、UI 变化、依赖、状态和验收证据，再更新总览。保留已有任务格式。

GitHub 是代码远程仓库，不默认发布 Issues、评论或 PR；按用户当轮要求执行对外操作。

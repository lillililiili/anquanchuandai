# 福大主动推送实施计划

**目标：** 沿用现有查询字段，在授权真实设备数据入库后可靠异步发送 POSITION、STATUS、ALARM；包含上线/离线变化，保留查询及国标代码。

**基线：** 3b95131，分支 codex/fuda-push-20261102；原目录前端未提交改动不迁入。福大未提供地址，用户已确认按 HMAC、HTTP 200 且整数 code=0 开发可配置发送端。

**约束：** 推送默认关闭；独立推送凭据与设备白名单；不部署、不改日常库、不控制设备、不提交或推送远程。使用 H2 MySQL 模式及本机随机端口模拟接收端；Java 8 源码兼容，构建 JDK 17。无自动删除推送记录。

**架构：** WearableBusinessStore.processReport 在内部报文处理事务中创建不可变位置/状态推送记录；业务快照提交时，基于原有报警日志生成新增报警任务，并捕捉在线变化。任务使用独立 outbox 表；租约领取、结果条件更新、退避重试。网络发送使用独立工作线程，定时器只唤醒。稳定事件 ID 在重试中不变，每次签名 nonce 更新。发送前再次检查当前授权。恢复/离线数据保留观测时间，不能作为当前状态。

分支：`codex/dm8-cluster-kylin-20261103`。开发基线：`2b6787aafaf87c5c17ba16e550ebc726d38ce2c6`。

## 已固定的范围

达梦 8 与 MySQL 两条运行路径；两组 Spring 应用与 Node 协议网关；共享 Redis；NAS/NFS 文件目录；Caddy HTTP/WebSocket 入口。不引入 K8s，不把应用双节点等同于数据库、Redis、入口、NAS 的高可用，不包括媒体服务多机调度或活动通话无感迁移。

开发验证使用独立工作树、独立数据库与模拟设备，不改日常环境和真实设备。正式迁移按“暂停写入—最终对账—单节点验证—第二节点加入—入口切换”执行。新库有新增数据后，回滚先处理新增数据。

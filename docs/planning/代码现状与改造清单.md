## 3 优先修复清单

P0 表示进入真实试点前必须解决，P1 表示生产候选前必须完成。下面是静态源码发现，未进行实际攻击测试或公网暴露探测。

### C01 P0 业务授权不足

安全配置仅对大部分业务要求登录；在所扫描的 melhat Controller 与 helmet 业务服务中未检索到 `PreAuthorize` 或 `DataScope`。设备详情和写操作按传入 ID 执行，通用框架具有权限能力不代表业务已经使用。

应在服务端校验操作权限和对象范围，并覆盖列表、单条详情、导出、通信和批量 ID。验收：只读账号写入失败；跨厂站 ID 无法读取或修改，管理员人员列表权限不作为普通业务人员选择的前提。[SecurityConfig](<E:/沉积岩/anquanchuandai/后端代码/melhat_server-dev/ruoyi-framework/src/main/java/com/ruoyi/framework/config/SecurityConfig.java:114>)、[设备写入服务](<E:/沉积岩/anquanchuandai/后端代码/melhat_server-dev/ruoyi-system/src/main/java/com/ruoyi/helmet/service/impl/SafetyHatInfoServiceImpl.java:141>)

### C02 P0 回调与 WebSocket 身份不可信

`/ext/**`、`/ws/**` 在匿名允许列表。设备回调以帽号和业务字段为主要校验，随后落库；WebSocket 使用客户端自报 ID，广播遍历所有连接。旧连接关闭会按 key 直接删除映射，可能影响同 key 新连接。

应加入可信回调认证、防重放和幂等；握手使用认证身份，按授权范围推送；关闭时核验具体 Session。验收包括假签名、重复消息、账号失效、同 ID 重连和跨厂站消息隔离。[回调](<E:/沉积岩/anquanchuandai/后端代码/melhat_server-dev/ruoyi-admin/src/main/java/com/ruoyi/web/controller/business/ExternalController.java:73>)、[WebSocket](<E:/沉积岩/anquanchuandai/后端代码/melhat_server-dev/ruoyi-system/src/main/java/com/ruoyi/system/websocket/WebSocketSever.java:38>)

### C03 P0 SOS 假接通与处置竞态

后端 `answer` 只检查未处理并返回成功，没有认领、通话凭证和实际建立通话；PC 随即显示“呼叫已接通”。`handle` 忽略服务返回布尔值，服务先读再更新，缺少条件更新保护。

建立事件认领和独立 CallSession；只有 RTC 成功建立后显示接通；不存在或冲突返回明确失败。验收两人同时接听、第三方超时、无音视频能力设备、服务重启和重复提交。[后端 answer](<E:/沉积岩/anquanchuandai/后端代码/melhat_server-dev/ruoyi-admin/src/main/java/com/ruoyi/melhat/controller/RealTimeAlarmController.java:89>)、[PC handleAnswer](<E:/沉积岩/anquanchuandai/pc前端代码/melhat_pc-main/src/views/sos/index.vue:365>)、[处置服务](<E:/沉积岩/anquanchuandai/后端代码/melhat_server-dev/ruoyi-system/src/main/java/com/ruoyi/helmet/service/impl/RealTimeAlarmServiceImpl.java:59>)

### C04 P0 设备和人员身份仍是单帽模型

设备行保存当前绑定人，服务限制同一人员再绑定另一帽子；没有通用佩戴区间和独立 Person。回调使用当时查询到的当前绑定人，迟到上报可能错归属。

新建 Device/Person/Assignment，保留旧帽 ID 映射，事件使用发生时的人员和厂站快照。验收帽带并用、同设备领用冲突、历史换绑、资产跨厂调拨和未知历史。[SafetyHatInfoServiceImpl](<E:/沉积岩/anquanchuandai/后端代码/melhat_server-dev/ruoyi-system/src/main/java/com/ruoyi/helmet/service/impl/SafetyHatInfoServiceImpl.java:141>)

### C05 P0 登录资料与日志敏感字段

`SysUser.getPassword()` 未见忽略序列化注解，`getInfo` 返回 user 对象；HTTP 转换器中自行创建 ObjectMapper。存在密码字段进入响应的源码风险，应以真实 MVC 响应测试确认并修复，不能只测试单独的 ObjectMapper。

改用安全 DTO 或明确只写字段，统一序列化配置；App/后端日志脱敏。验收检查 HTTP JSON 不包含 password，数字版本字段与 ID 精度策略一致。此处不展示或读取任何实际账号密码。[SysUser](<E:/沉积岩/anquanchuandai/后端代码/melhat_server-dev/ruoyi-common/src/main/java/com/ruoyi/common/core/domain/entity/SysUser.java:277>)、[getInfo](<E:/沉积岩/anquanchuandai/后端代码/melhat_server-dev/ruoyi-admin/src/main/java/com/ruoyi/web/controller/system/SysLoginController.java:68>)、[转换器](<E:/沉积岩/anquanchuandai/后端代码/melhat_server-dev/ruoyi-framework/src/main/java/com/ruoyi/framework/config/WebDataConvertConfig.java:22>)

### C06 P0 文件下载代理边界

下载服务直接请求记录里的 fileUrl，并将字节返回，缺少可见的可信目标、大小和跳转约束。若记录可由调用方提供 URL，形成服务端请求不可信地址的链路；实际可访问范围取决于部署网络。

优先使用可信对象存储键，由后端签发下载；若保留代理，限制协议、域名、解析 IP、重定向、超时和响应大小，同时校验文件对象权限。[下载服务](<E:/沉积岩/anquanchuandai/后端代码/melhat_server-dev/ruoyi-system/src/main/java/com/ruoyi/helmet/service/impl/FileRecordServiceImpl.java:88>)、[文件 Controller](<E:/沉积岩/anquanchuandai/后端代码/melhat_server-dev/ruoyi-admin/src/main/java/com/ruoyi/melhat/controller/FileRecordController.java>)

### C07 P0 演示兼容缺少可见的生产开关隔离

### C08 P0 到 P1 指令和通话缺少结果闭环

### C09 P1 在线口径和统计不一致

设备查询先按数据库 status 过滤分页，再调用外部平台刷新返回对象；新建设备默认 status=1；统计直接读库。列表筛选、展示和统计可能不同。新平台必须区分资产状态与遥测状态，并以同一可信快照聚合。

验收新增设备状态未知、第三方不可达、分页在线筛选、调组删设备、人数去重和数据过期。[状态刷新](<E:/沉积岩/anquanchuandai/后端代码/melhat_server-dev/ruoyi-system/src/main/java/com/ruoyi/helmet/service/impl/SafetyHatInfoServiceImpl.java:83>)、[默认状态](<E:/沉积岩/anquanchuandai/后端代码/melhat_server-dev/ruoyi-system/src/main/java/com/ruoyi/helmet/service/impl/SafetyHatInfoServiceImpl.java:162>)、[统计服务](<E:/沉积岩/anquanchuandai/后端代码/melhat_server-dev/ruoyi-system/src/main/java/com/ruoyi/helmet/service/impl/DataStatisticsServiceImpl.java>)

# S7 交接单（给 Android 协作者 B）

日期：2026-09-09  
契约：[s7-call.md](../contracts/s7-call.md)  
依赖：S1–S6。测试库再执行 `V007__call_and_command.sql`。

通话与播报走新接口。认领成功 **不等于** 接通。通话失败 **不**关闭 SOS。TTS 接口成功 **不等于** 现场已听到。`demo: true` 不得当生产 RTC。

旧 `/hat/intercom/**`、`/hat/tts/**` 仍给旧页，不要当本模块真相。

## 联调

- `POST /api/v1/calls` `{ deviceId, eventId?, kind: "single"|"sos", video?, idempotencyKey? }`  
  目标以 **deviceId** 为准；仅 eventId 时用事件快照设备。无 `intercom` → **409**「该设备不支持通话」。
- 成功 `data.status` 为 `offered`（待加入），**不是** `connected`。`credentials` 仅此次与 credentials 接口带 token。
- `GET /api/v1/calls/{id}` 无 token 明文  
- `GET /api/v1/calls/{id}/credentials` 仅发起人  
- `POST /api/v1/calls/{id}/joined` `{ agoraUid }` 成员须匹配 → `connected`  
- `POST /api/v1/calls/{id}/end` 重复 **200**  
- `GET /api/v1/events/{id}/calls`、`GET /api/v1/devices/{id}/calls`
- `POST /api/v1/commands/tts` `{ deviceIds, text, eventId?, idempotencyKey? }`  
  每设备一行：`accepted` | `sent` | `failed` | `unknown`。`heard` 当前恒为 false。
- `GET /api/v1/commands/{id}`

状态：`requesting → offered → connected → ended`；非终态可 `failed` / `timed_out`。仅 `connected` 可展示「已接通」。`offered` 超过 60 秒未 joined，下次读取变为 `timed_out`。

权限：查询=授权厂站内值班/班组长/复核/只读/设备管理员/平台。发起/joined/结束=值班+班组长。TTS=值班/班组长/设备管理员/平台。只读与平台发起通话 **403**。隐藏按钮 ≠ 已授权。

本机 `melhat.demo-mode`：**不**调 Headband；凭证 `demo:true`。

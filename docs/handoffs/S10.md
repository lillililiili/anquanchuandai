# S10 交接单（给 Android 协作者 B）

日期：2026-09-09  
契约：[s10-location.md](../contracts/s10-location.md)  
依赖：S1–S7、S9。测试库再执行 `V009__location_and_fence.sql`。

人员主位置与轨迹只来自 **当前/当时领用的安全帽 GNSS 样本**。安全带不打点。楼层未知不编造。`locationQuality` 非 `ok` 或已陈旧 **不得**画成越界违章。`demo: true` 不得当生产在线。

旧 `/hat/electronic/fence/**` 仍给旧页，不要当本模块真相。

## 联调

- `GET /api/v1/locations/people`、`GET /api/v1/locations/people/{id}`
- `GET /api/v1/locations/people/{id}/tracks?from&to&current&size` 上限 500，超出抽稀。跨站 403。空列表 200
- 位置对象：`personId, personName, deviceId, sn, lat, lng, occurredAt, locationQuality, connectionQuality, source, floor, floorSource, demo`
- `floor` 恒为 `null`，`floorSource=unknown`
- `GET /api/v1/fences`、`GET /api/v1/fences/{id}` 只读即可；绘制与启用由 PC
- 围栏事件：`type=geofence` `source=geofence`，字段 `fenceId` `fenceAction`（`enter`/`leave`）`ruleVersion`

坐标系 WGS84。陈旧窗默认 180 秒（与 S6 相同）。隐藏按钮 ≠ 已授权。

## 契约

- 统一约定：[docs/contracts/00-common.md](../contracts/00-common.md)
- 登录仍走旧路径：`POST /login`、`GET /getInfo`、`POST /logout`、`GET /captchaImage`
- `GET /getInfo` 的 `user` **不再包含 `password`**。请按安全 DTO 解析（`userId`、`userName`、`nickName`、`avatar`、`roles` 等）

## 本轮已收紧、可能影响客户端的行为

1. `/api/melhat/**`、`/monitor/job/**`、`/test/**` 不再匿名。
2. `/ext/**` 与 `/aip/head/band/location` 需要请求头 `X-Melhat-Callback-Token`，与配置 `melhat.callback.token`（环境变量 `MELHAT_CALLBACK_TOKEN`）一致。未配置则全部拒绝。完整 HMAC 在 S6。
3. `prod` profile 不加载 `DemoCompatibilityController`；`melhat.demo-mode` 默认 false，仅 `dev`/`test` 打开。
4. WebSocket `/ws/**`：`dev` 仍可匿名（兼容现有 App）；`prod` 需要已登录。PC 已在握手 URL 带 `token` 查询参数。建议 Android 尽快同样带上，S6 将强制。
5. 若依认证失败入口仍可能返回 **HTTP 200 + `code:401`**。设备回调过滤器对缺失 token 使用真正的 HTTP 401。PC 对两种形态都按未登录处理。

## 本轮未稳定、不要当完成接口

- 人员 / 通用设备 / 领还 / 统一事件 / 安全带
- SOS 真实接听与 RTC（PC 已去掉“呼叫已接通”）
- `/system/space`、`/system/module`、`/system/hat`、有限空间页：演示兼容，非生产
- 文件下载代理仅加了协议/超时/大小/地址限制，不是对象存储

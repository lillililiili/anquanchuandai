# 硬件供应商待确认清单（S0-08）

本清单只列尚未向供应商关闭的问题。S0 **没有**对接安全带，也没有把现有 Headband HTTP 调用当成已验收的真实接入（真实接入在 S6/S8）。

## 安全帽（现有厂商接口资产：`headband` 配置）

| 编号 | 问题 | 状态 |
| --- | --- | --- |
| H-HAT-01 | 可交付样机数量、SN 清单、是否允许实验室长期留样 | 待确认 |
| H-HAT-02 | 官方协议文档版本；告警 `type` 枚举与平台事件类型对照表 | 待确认 |
| H-HAT-03 | 回调认证方式（HMAC / 静态 token / mTLS）、防重放时间窗、时钟偏差 | S6 已实现 token 必填 + 可选 HMAC（`X-Melhat-Timestamp/Nonce/Signature`）。书面协议仍待确认 |
| H-HAT-04 | GNSS / 告警 / SOS 上报频率、离线补传、乱序与迟到数据规则 | 待确认 |
| H-HAT-05 | 设备回执：指令（TTS、对讲、结束通话）成功/失败/超时如何返回 | 待确认。S7 已按设备落 `accepted/sent/failed/unknown`，`heard` 在无回执前恒为 false，不得标「已听到」 |
| H-HAT-06 | RTC 通道：声网 AppId、频道、token 有效期、无视频型号如何表达 | 待确认。S7 仅 `connected`（客户端 `joined` 且 uid 匹配）可显示「已接通」；demo-mode 凭证 `demo:true`，不调厂商 |
| H-HAT-07 | 网络：设备出网、平台入向 IP/端口、是否必须公网、TLS 要求 | 待确认 |
| H-HAT-08 | 电量、在线、佩戴检测的语义与过期时间 | S6 默认陈旧窗 180 秒（`melhat.telemetry.stale-after-seconds`），书面语义待确认 |

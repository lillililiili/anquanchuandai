## 联调要点

- 连接：看 `connectionQuality`（`unknown` / `ok` / `stale`）。`online == null` 是未知，不是离线。默认 180 秒无新上报为陈旧，不改成 offline。
- 事件：`source=helmet` 为设备上报。人员快照仍是发生时领用。`demo: true` 不得当生产在线。
- SOS 入库 **不等于** 通话接通（S7）。
- 过期语义由服务端计算，不要在客户端用定时器猜在线。

## 样机回归（有真帽时）

1. 设备台账 SN / `externalCode` 与帽号一致，已分配厂站。  
2. 厂商回调带 `X-Melhat-Callback-Token`（HMAC 头仅在平台配置了 secret 后才要求）。  
3. 上报 SOS/GNSS 后：设备 `lastReportedAt` 更新；事件列表出现对应记录。  
4. 重复同一报文只加 `repeatCount`。

实验室可用 `POST /api/v1/ingest/replay`（非 prod + demo-mode，设备管理员）。

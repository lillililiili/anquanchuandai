# V2-2：现场监看与资料基础

更新：2026-09-19。结论：V2-2纯前端演示闭环完成，不代表真实设备、存储、权限或生产验收。

## 运行与范围

新前台目录运行 `npm run dev:mock`，访问 http://127.0.0.1:5179，选择“演示负责人”。构建命令 `npm run build:mock`，`npm run preview:mock` 在5180预览。负责人可执行本阶段内存操作；核验员、只读查看员只能查询。

本轮只修改新前台、测试和文档；不修改或启停后端、数据库、旧PC、安卓及相关服务，不升级依赖。七个一级菜单保持不变。全部业务修改和文件只保存在当前页面内存：切页保留，刷新恢复种子，文件及关联一起消失。模拟登录仍使用独立sessionStorage，不是服务器认证。

## 已交付

1. 位置、视频、轨迹、围栏共享同厂站设备选择；目标页不能匹配时说明原因，不选首台设备替代。围栏只按厂站查看，不推定设备绑定。切站和失效清理共享选择。
2. 位置显示坐标系、来源、源时间和有依据的精度；未知不补数。RTK/UWB能力不视为实际高精度定位。继续使用WGS84无外部底图矢量地图；围栏图层独立加载、选择可进入围栏页。超过图层当前读取范围时明确提示不完整。
3. 围栏支持绘制、节点拖动、坐标表键盘编辑、撤销、保存、启停、删除及版本历史，规则区分禁入/禁出及适用对象。简单多边形校验拒绝无效坐标、重复顶点、共线退化及自相交。未保存离开确认，失败保留草图；删除保留内存版本。
4. 资料支持本地导入、预览、下载、删除、人工人员/作业/事件关联及证据选择。明确区别仅元数据、浏览器内存文件与设备本地文件声明；不把本地录像能力当作已有文件。
5. 允许JPEG、PNG、WebP、MP4、WebM、MP3、WAV、OGG；单文件50MB、总Blob预算200MB。校验扩展名、MIME、文件头和当前浏览器解码，失败明确拒绝；不接受SVG、HTML、任意URL，不自动淘汰证据。
6. SHA-256摘要及资料版本随证据引用冻结；既有核验记录中的证据同样锁定。冻结版本不可覆盖/删除。人工关联明确不是历史归属证明，不改变旧事件/轨迹/核验事实。事件影像区展示授权冻结元数据，但不替代核验提交。
7. 文件在内存Blob集合中，元数据只有资料标识，不含磁盘路径或播放地址。预览按需创建对象URL，关闭、切对象、切站、失效及卸载时释放。下载只从已授权资料对应Blob创建本地链接，无网络上传。

## 实现入口与一致性

- `src/mock/spatial-service.js`：查询、范围/角色/版本校验、围栏与资料命令、版本历史、引用冻结。
- `src/mock/spatial-provider.js`、`transport.js`：沿用请求取消和会话代次校验，提交前重新检查；事务副本提交并通知刷新，同操作标识同输入返回原结果，不同输入拒绝。
- `src/mock/local-file.js`：类型、大小、文件头、解码及临时URL释放。
- `src/mock/FenceEditor.vue`、`FenceCanvas.vue`、`MaterialActions.vue`、`EvidencePicker.vue`：仅Mock构建引入的操作界面。
- `src/mock/useLocalEditor.js`：编辑离开确认、取消与会话清理，hash变化不提前关闭确认框。
- `src/utils/fence-geometry.js`：纯几何校验；`useS2Workspace.js`：修订刷新、合法选择与空页回退。
- `@spatial-actions`、`@fence-editor`、`@material-actions` 构建期别名隔离；正式、预发布、数据库demo使用关闭实现，不新增后端写请求。

以上只保证单页面演示一致性，不宣称服务器并发或安全隔离。

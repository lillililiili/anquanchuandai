# V2-7 工作台、统计与汇报交付记录

日期：2026-09-20。交付范围：新前台纯内存演示；真实设备、正式数据和生产安全未验收。

## 实现

- 工作台保留25人、68件装备、15件未完成事件的一号站基线，增加活动协同及待回执广播提醒、统计入口。事件计数按平台/来源身份去重。
- 查询分析 → 统计报表开放综合、人员、装备、任务、事件五视图；快照和历史区间明确分开，事件按厂站时区分日，UTC半开区间筛选。
- 当班、装备关系、类型/型号、视频装配、通信、新鲜度、监护阶段、事件阶段、显式完成、资料采集/接收分别统计。未知与冲突不进入领用率分母。未提供无依据的视频可用率或健康分数。
- 轻量可键盘点击条图和统计卡共用明细集合；每页20条，CSV导出整个所选口径，包含模拟说明、厂站、时间、分母说明和防公式注入处理。
- 显式完成时间取新增 `timeline.action = complete` 操作事实；种子完成快照、草稿、核验提交和模拟回执不计入。没有用设备上报时间或事件发生时间替代完成时间。
- 请求使用既有 Mock transport、取消/会话版本及 usePortalQuery；路由白名单保留厂站、视图及合法UTC范围。切厂站、身份失效清空明细，业务修订重新查询。
- 模型分组名称及日分组在来源不可用时不泄露；不可用分区不返回计数或明细，不用0代替。
- 构建期 `@statistics-view` 隔离模拟统计，非Mock模式明确未接入。无新增依赖、接口部署、数据库操作或真实设备请求。
- 清理过时的“FE3才开放视频”元数据提示、事件作业摘要标题；保留真实未接入入口及禁用原因。

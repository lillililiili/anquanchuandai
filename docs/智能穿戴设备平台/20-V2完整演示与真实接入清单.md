# V2 前端演示与评审交付

日期：2026-09-20。用途：领导评审业务原型，不是生产系统验收。

## 运行和边界

在 `pc前台代码/wearable-portal-web` 执行 `npm run dev:mock`，打开 `http://127.0.0.1:5179`；已有服务时不要重复启动。选择“演示负责人”，不需要账号密码，也不连接真实认证服务。构建与预览：`npm run build:mock`、`npm run preview:mock`，预览为 `http://127.0.0.1:5180`。

切换菜单保留本页内存数据，完整刷新恢复初始数据；顶栏场景面板支持恢复初始数据并退出身份。不存在 IndexedDB 或业务持久化。演示数据不可作为真实台账保存。核验员及查看员的差异属于交互演示，不是客户端安全隔离。

正式 / 预发布 / 数据库 demo 不提供本轮 Mock 统计、模拟通信或领用写服务。已有后端、原 PC、Android、数据库、账号和设备没有因本轮修改。

## 四条汇报演示脚本

每条脚本建议从刷新后的一号站开始。以下是供人工汇报的完整操作说明；专项自动化范围以验证记录19为准，不将人工尚未确认的汇报脚本写成领导验收通过。

### 1. 人员 → 装备 → 作业 → 归还

1. 工作台确认已领用装备68台、当班25人。进入人员装备，打开演示人员1-02。
2. 在安全帽槽位领用可用装备；查看同一人员和 `device-1-2-helmet` 设备详情的当前关系。
3. 进入该人员关联作业监护，确认人员装备显示相同的当前关系；仅查看，不把台账领用解释为安全许可。
4. 返回设备详情归还；再次进入人员历史查看新增领用、归还两条流水。
5. 查看工作台和统计装备页：68→69→68。过去事件、资料和轨迹的历史归属不随领用变化；刷新后流水恢复种子。

### 2. 工作台 → 事件核验 → 本地完成 → 统计

1. 工作台“重点关注”进入演示事件1摘要，再打开核验详情。
2. 认领、转现场核验。查看事实位置 / 影像：缺少历史证据时保留未知，当前设备画面不是事件录像。
3. 编写核验，填写现场情况并选择结论；需要处理时填写措施。可选择当前厂站授权资料，记录明确为模拟证据。
4. 保存草稿并重新打开，提交形成不可修改的版本。无法确认不能完成；有效提交也不会自动完成。
5. 由事件负责人显式“完成本地跟进”。工作台未完成事件减少，统计“区间显式完成跟进”增加1，点开明细核对同一事件。
6. 两类回执模拟成功或失败仍独立；不表示已发送外部安监系统或原系统结案。

### 3. 模拟视频 → 资料 → 核验证据

1. 从现场监看进入视频，选择配置允许且未开启隐私的演示安全帽（如一号站设备1），进入单路。
2. 显式播放本地合成视频，确认画面标有模拟字样；演示抓拍，或录制短片后明确保存。不访问设备摄像头。
3. 进入现场资料查看产生的元数据和本机预览。设备拍摄时间未知时不能用本机生成时间替代。
4. 在待现场核验事件中选择这份资料、提交核验；查看资料标识、版本和摘要冻结的引用记录。
5. 录像受浏览器 MediaRecorder/编码支持限制；不支持时禁用，不用成功提示替代媒体。离开前未保存片段不自动上传，刷新清空本机资料。

### 4. 模拟 SOS → 调度 → 事件跟进

1. 演示面板读取求助对象并触发模拟 SOS，打开紧急详情。
2. 只展示有证据的设备、位置快照。历史人员归属缺失时保持未知，不能用当前佩戴人补全。
3. 若所选设备模拟通信能力已配置，选择联系人发起模拟单呼 / 群呼，逐人演示接通、拒接、超时和退出。
4. 多人呼叫中的部分接通不等于全部接通。切页观察顶栏会话提示和工作台协同提醒。
5. 显式结束协同，再进入事件认领和后续核验；结束会话不完成事件。
6. 安全带电话 / 手表协议未知时可展示 SOS 事实，但联系入口禁用；不建设另一套 RTC 或真实设备电话。

## 统计说明

- 五视图：综合、人员、装备、任务、事件。当前快照不随历史区间变化；历史使用 UTC 起止时间 `[from,to)`，按厂站时区分日，缺失或非法时区回退 UTC。
- 当班按名册 personId 去重；设备按 deviceId 去重。默认一号站领用率68/71；未知和冲突不进入分母，不能写成68/全部设备。
- 事件按平台 ID 和来源系统/事件 ID 去重；阶段快照中的“来源标记本地完成”与区间内显式 complete 操作分开。提交、回执不计完成。
- 事件未知发生时间、资料未知采集时间独立；采集和接收两个口径不能相加作为资料总数。
- 类型、型号、视频装配、通信和新鲜度独立。文档声明、模拟配置和真机验证不同；不输出真实视频可用率、健康评分或风险热力图。
- 图表 / 统计卡打开同一集合的分页明细，本地 CSV 导出全口径明细而非当前页，含模拟标识、厂站、区间和导出时间，防公式注入。

## 评审需要确认的决策

1. 七菜单与各工作区职责；人员、设备主数据维护继续放后台。
2. 谁能领用 / 归还，未知与冲突关系的核实责任；离线只提醒是否符合现场制度。
3. 人形体征指标、单位、来源时间、适用型号和隐私授权；缺数不默认健康正常。
4. 围栏规则、坐标系统、历史归属和资料分类；围栏保存不能直接视为真实违规判断。
5. 认领 / 转交 / 核验结论 / 必填字段 / 显式完成规则与回传职责。
6. 作业监护与工作票许可关系；人工检查不取代设备报告或安全许可。
7. 呼叫参与者状态、广播回执、SOS责任和跨页面会话处理。
8. 统计分母、时区、导出字段及历史时间范围。本轮 UTC 文本输入可在评审后增加厂站时区日期选择器，但不能默认浏览器时区。

## 真实接入与未验证能力清单

| 范围 | 接入前需要的证据 / 方案 | 当前结论 |
| --- | --- | --- |
| 登录与权限 | 正式账号、角色、厂站和对象范围，服务端授权 | 仅隔离契约测试；无真实权限验收 |
| 主数据 | 人员、设备、班次和名册的权威来源及历史关系 | 合成主数据，不从 sys_user 推断 |
| 领用与写入 | 事务、唯一约束、幂等、并发版本、审计、迁移 | 当前只保证单页面演示一致性 |
| 安全帽 / 安全带 / 手表 | 厂家协议、型号选配、实例装配和字段单位 | 文档 / 模拟能力，不是真机能力 |
| 生命体征 | 指标来源、佩戴关系、隐私授权、阈值依据 | 不做医疗判断；真机未验证 |
| 定位与围栏 | 坐标系、地图授权、场地配准、定位质量、持久化 | 无外部底图；未知坐标不落点 |
| 视频 | 媒体协议、短期凭据、失效策略、授权、编码兼容 | 本地合成画面；真流及FLV链路未验收 |
| 文件与证据 | 受控存储、内容检测、访问权限、版本/摘要保全 | 本机内存文件；刷新丢失 |
| 核验与回传 | 不可变提交版本、幂等回传、外部状态和审计 | 显式模拟回执；没有外部发送 |
| 作业监护 | 作业和许可来源、参与名册、检查责任及闭环规则 | 本地状态不是作业许可 |
| 调度与SOS | 唯一RTC会话、设备应答、媒体权限、连接生命周期 | 纯状态模拟；无麦克风、摄像头和RTC |
| 统计与运行 | 服务端全量聚合、历史归档、性能、安全和兼容 | 小规模内存演示；不能替代生产验收 |

下一步是领导评审并记录需求变更；不得因本轮前端交付自动启动后端开发、数据库迁移、真实设备命令或生产部署。

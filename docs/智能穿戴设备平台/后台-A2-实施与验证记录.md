## 接口及数据边界

新增的均为前端函数调用，不是真实HTTP接口：

| 分类 | 服务 |
| --- | --- |
| 查询 | devices、device（兼容旧调用）、deviceOptions、deviceHistory、deviceChanges |
| 命令 | devices.create、devices.update、devices.configure |
| 字段 | manufacturer、sn、modelId、assetCode、purchasedOn、remark、assemblies、connection、verification、capabilitySource |

命令按字段白名单拒绝生命周期、设备源时间、通信、领用人与真实验证修改。更新校验原对象与目标区域权限、设备版本及关联区域版本；幂等重试重新检查权限。无权403、不可见404、版本/唯一冲突409。详情审计按当前设备权限及记录范围过滤，无审计权限不返回完整差异。

页面内存切页保留，刷新恢复种子；只使用独立Mock身份sessionStorage键，不触碰原模式或前台Token。设备资产信息不含密码、凭据、文件地址或连接参数。

# FE0 内存 Mock 调整记录

## 本次决定

按用户最新要求，取消 IndexedDB 持久化，改用页面生命周期内共享的 Mock 数据仓库和 Pinia 页面状态。刷新或重新打开页面恢复初始数据与正常场景；页面内切换菜单不重置。模拟登录仍使用独立 sessionStorage，不是真实认证。

原数据库演示工程、后端及已有浏览器 IndexedDB 数据均未修改或删除。新 Mock 代码不再读取或写入旧演示数据库；无需迁移。业务操作尚未开放，后续 FE1–FE6 的模拟变更也只需通过统一内存仓库更新。

- README 补充 `dev:mock`、`build:mock`、`preview:mock` 及存储生命周期说明。

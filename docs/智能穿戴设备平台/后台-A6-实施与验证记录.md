# 后台 A6：模拟接入、同步任务与审计界面

日期：2026-09-20。工程：`pc前端代码/melhat_pc-main`，分支`codex/admin-a6`，基于`fd423ab`。仅修改后台纯前端Mock、专项测试及文档，原有`docs/analysis/`保留。未推送或合并。

## 实施结果

- 六类连接器：DEVICE、PERSON、WORK_TICKET、SAFETY、SUMMARY_RETURN、VERIFICATION_RETURN。地址只能选受控示例标识，假凭据只读，成功测试仍为“未接入”。
- 确定性成功/超时/字段不匹配，记录配置版本和每次尝试；厂站默认场景被未指定独立场景的连接器实际消费。
- 设备/人员预览后确认。设备按厂家与SN，人员按来源系统与来源ID匹配；同名不合并。映射缺失和身份冲突阻止整批导入。
- 确认重验配置、目标、映射、授权快照和创建者。旧预览409；operationId幂等，重试保留同一任务；记录新增/更新/跳过/冲突数量。
- 仅导入白名单来源字段，保护领用、生命周期、授权、人工内容与历史。需对应目标全厂站读写权限；无读取权限的任务详情404，列表先过滤再计数。
- 工作票/安监仅映射和回执，摘要/核验回传各自独立，不生成作业、事件或结案，不真实外发。
- 审计按厂站、时间、账号、对象、动作、结果筛选，详情保留脱敏快照与差异。任务与设备/人员对象审计在同一内存事务提交，重复确认不重复审计。
- CSV导出全部授权筛选结果，含模拟标记、范围、时间与记录数，处理公式前缀/引号/控制字符；无编辑和清空日志功能。
- 草稿离开确认、切站/身份清理和异步取消；表单aria-busy；旧预览被拒绝并关闭弹窗后，错误摘要获得焦点。

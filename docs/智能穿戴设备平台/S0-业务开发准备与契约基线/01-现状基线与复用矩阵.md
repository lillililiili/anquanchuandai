## 3. 功能去向与复用判定

“复用”是开发路径，不表示已通过真机测试。

| 能力 | 前台去向 | 分类 | 需处理 |
| --- | --- | --- | --- |
| 登录/用户信息 | 现有登录和守卫 | 直接复用 | 补真实账号验证；不增加假登录 |
| 安全帽分页与列表 | S1装备聚合来源 | 适配复用 | current/size、R<Page>、列表平台在线与本地详情差异 |
| 当前绑定 | 人员三装备展示 | 需要扩展 | bindUserId不是独立personId；多绑定不能只取首条 |
| 领用历史/班次 | F03/F07 | 待新增 | 当前bindTime不能还原历史，用户列表不是当班名册 |
| 设备同步/台账维护 | 管理后台 | 适配复用 | 前台加载不触发sync、save、updte、绑定写入 |
| 厂站与区域授权 | 顶栏及全页数据范围 | 需要扩展 | 不把部门树当厂站范围 |
| 定位/轨迹 | S2地图和历史回放 | 适配复用 | 坐标系、源时间、缺口、历史绑定，当前设备快照不代表发生时归属 |
| 围栏 | S2 | 需要扩展 | 范围、版本、启停、进出判定和授权 |
| 资料 | S2/F03引用 | 需要扩展 | 分页、拍摄/接收时间、对象鉴权、真实文件上传 |
| 视频/RTC | S3/S6 | 适配复用 | 媒体权限、生命周期、续期与逐端回执 |
| 原报警 | S4事件来源 | 需要扩展 | isHandled不等于正式核验，原始事件防重 |
| TTS/对讲 | S6 | 需要扩展 | 成员/任务状态、演练隔离；有源码不等于设备已执行 |
| 作业与核验 | S4/S5 | 待新增 | 独立来源摘要、证据、核验和回传状态 |
| 总览/统计 | S7 | 需要扩展 | 在线帽数不是当班人数；电量阈值不是设备安全结论 |
| /aip部分兼容入口 | 不作为生产默认来源 | 仅演示 | 按具体路径确认，不把整个/aip族一概视为演示 |

旧后台继续承载台账、领用、授权和配置；安卓保留旧能力。跨端权限缺口应后续共同修复，不能仅限制新前台而留旧API绕过。

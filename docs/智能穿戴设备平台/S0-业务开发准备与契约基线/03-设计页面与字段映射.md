## 3. F07逐字段对应（以04定义的DTO为准）

| 位置/字段 | 契约字段 | 来源或缺口 | S1交互 |
| --- | --- | --- | --- |
| 姓名/编号/头像 | Person.name/personCode/avatarUrl | 名称可通过确认过的用户→人员映射；人员编号待主数据；头像仅合法授权URL | 无头像用文字头像；编号未知显示--，不借用帽SN |
| 厂站 | siteId；context.sites | 独立厂站授权待补，deptId不能代替 | 顶栏决定当前厂站；页内“全部”仅当前授权范围，不扩大查询 |
| 班组 | team | bindGroup可能是通信组，不直接映射 | context.teams已就绪才启用 |

| 当前作业/岗位/监护人 | works Section | 来源未接入为NOT_INTEGRATED | 禁用未支持筛选；不把未知显示“待分配” |

| 最近更新时间 | dataUpdatedAt | 仅可验证业务源更新时间；没有则null | 显示--，另以根asOf显示本次查询时间 |
| 行序号 | 分页派生 | (pageNum-1)*pageSize+index+1 | 不作为人员ID |
| 手机 | phoneMasked | 服务端脱敏，映射或授权不充分为null | 不返回原身份证/地址/签名等SysUser字段 |

| 视频/对讲/事件 | actions.viewVideo/talk/viewEvent | 能力和权限双重判断 | S1未实现目标时禁用并说明原因，不发命令 |

列表默认不自动选择第一人，右栏显示“请选择人员”；点击行读取该人的详情，点击“查看详情”进入F03。分页/筛选变更后清空选中，防止右栏展示不在结果中的旧人员。路由保存pageNum/pageSize/keyword/teamId/workState/shiftId/selectedPersonId及siteId；关键词确认或回车再查，不每键请求。关闭右栏清除selectedPersonId。

## 4. F03逐字段对应

| 面板 | 契约 | 显示规则 |
| --- | --- | --- |
| 人员头卡 | person + duty | “在岗”仅有名册/在岗来源才显示；无班次未知，不从online推算 |
| 装备卡 | equipment槽位/Device | 名称、编号、型号、通信、电量及其源时间；不显示未确认厂家传感项 |
| 位置面板 | location Section | sourceDeviceId、坐标系、源时间、质量；S1无已验证地图时显示明确状态，不放PDF示例点 |
| 领用绑定历史 | historySummary + 独立equipment-history分页 | 动作、类型、编号、经办人、生效起止、状态、证据程度；迁移当前绑定不是“领取”动作 |
| 作业信息 | works Section | 编号/名称/区域/监护人/负责人/时间/成员/来源与本地状态；未接入保留面板 |
| 待核验事件 | events Section | source/type/occurredAt/status与eventId；旧alarmCount不当成待核验数 |
| 视频 | media Section、actions | S1不自动起流；不可用时禁用按钮，不展示演示视频当现场 |
| 返回列表 | 已验证站内returnTo +路由查询 | 恢复筛选和分页；外部或未知returnTo回/personnel |

S1列表与详情只实现已定义只读数据展示。作业、事件、位置和媒体的完整子页面仍在后续阶段；详情中的未来模块Section固定存在且可为NOT_INTEGRATED，禁止凭页面图临时拼接错误的旧统计值。

## 5. 公共状态及素材验收

每一页都覆盖：首次加载骨架；AVAILABLE空数组的“暂无记录”；NOT_INTEGRATED的“数据待接入”；UNAVAILABLE的错误重试；FORBIDDEN的不显示受限内容；STALE的最后有效时间与提示。写操作再补提交中、冲突、失败保留输入和离开确认。

布局对照1672×941及1440×900，发布前补1920×1080。F07保持右详情层级；F03保持左右分栏；较窄窗口局部滚动或抽屉，不整页等比例缩小。统一深蓝、青色分隔及蓝按钮，不机械保留参考图重复/错位菜单图标。

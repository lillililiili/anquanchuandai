# 合成样例与验收场景

## 样例性质

fixtures/s1-cases.json 是纯合成文档样例，不是已上线响应，不是模拟服务，也不包含真实账号密码。不接入现有登录或生产请求；本次没有创建账号。合成身份采用 syn- 前缀，长旧ID专门用于检查JavaScript精度风险。

cases中context / people / detail / history分别对应04的四个GET。query与pathParams展示输入形状；error用例的输入不表示必然触发错误，须在S1测试桩中显式控制故障或授权条件。

- people-equipment-states：安全帽已领用且平台查询离线，但源时间未知；带领用未知；表未领用以“已有权威关系源”为合成前提，不意味着真实环境已有该数据。
- stateSamples.stale：测试专用假设阈值30分钟，不能写入业务默认配置。
- history-snapshot：假设已建独立快照仓；并不表示当前系统存在这条历史。
- legacyExamples只是脱敏结构示例，不是本次真实接口取回的数据。

## 本次实际验证范围

运行 verify.mjs 只验证文档链接、17页映射覆盖、合成包核心结构和状态不变量，并包含反例检查。不是完整JSON Schema验证，不测试Vue页面、后端、权限隔离或真机；不能用脚本通过替代真实联调。

本次HTTP探测与旧工程已完成验证的历史记录详见01、02。S0没有重跑业务build/lint或真实登录，不新增“真实联调通过”结论。

S1真实验收记录应附：运行版本/模式、时间、请求路径与脱敏参数、HTTP及业务码、角色与授权厂站、预期/实际、证据位置、未验证原因。不得把Token、密码、身份证、原始电话或设备控制密钥保存到文档。

# V2-3：模拟视频与资料生成

更新：2026-09-19。V2-3纯前端模拟视频与资料生成闭环完成。本阶段仅新前台、测试与文档；不修改后端、数据库、原PC、安卓或依赖。不是真实媒体或生产验收。

## 已实现

- Mock专属播放器通过构建别名选择，正式/预发布/数据库demo继续使用原关闭播放器。固定本地合成WebM短片约97KB，仅Mock包包含；不读取路由、存储、元数据提供的任意媒体地址。
- 短片含“模拟视频·非现场画面”、采样帧序号、源时间未知说明，无现场照片、无音轨。用户显式播放；支持暂停、静音、全屏、失败手动重试，无自动重连。
- 复用原播放器事件、帧推进与清理；play()成功不等于播放中。补充循环短片时间回绕处理。通信、来源流状态、本机播放状态保持独立。
- 三种视频墙布局均使用同一设备标识去重；底部设备条没有第二播放器。切布局/所选设备销毁旧播放器，新布局不自动播放。
- 单路监看开放“演示抓拍”“开始演示录像”。从当前真实解码画面生成PNG或无声WebM，持续带模拟水印。录像最长60秒、单文件50MB，超大小拒绝，不静默存残缺文件。
- 生成后显示待保存区，用户显式“保存为现场资料”或“丢弃”。保存复用V2-2类型/解码/摘要/版本/事务/200MB总预算校验，失败保留待保存内容，相同操作标识重试不重复生成资料。
- 资料保存来源设备、MOCK_CAPTURE/MOCK_RECORD生成方式、本地生成时间；真实源拍摄时间保持未知，不复制当前佩戴人为历史归属。提供“查看生成资料”入口，复用资料预览、下载及引用冻结。
- 统一能力判断校验实例配置、接入来源、隐私与身份；带表不默认提供视频。演示负责人可采集保存，其他身份只能观看合成视频。
- 负责人可显式模拟“隐私上报开启/关闭”，不是远程设备命令。开启停止播放并禁止采集；关闭仍需手动播放。原型号/能力、历史证据及领用关系不被修改。
- 未保存内容切页面/厂站前确认；注销、会话失效、隐藏页面直接丢弃未保存媒体、停止录像和释放资源，恢复不自动播放。刷新后业务修改、文件全部清空。

## 演示步骤

1. 新前台运行 `npm run dev:mock`，访问 http://127.0.0.1:5179，选择“演示负责人”。
2. 进入现场监看→视频→一号站安全帽1→单路监看。点击“播放模拟视频”，观察帧号及播放状态。
3. 演示抓拍→保存为现场资料→查看生成资料→预览/下载；核对设备编号、模拟生成方式和未知历史人员。
4. 返回单路监看，手动播放→开始演示录像→停止录像→确认保存→资料中播放。未保存离开可选择继续查看或丢弃。
5. 开启模拟隐私上报，确认播放和采集停止；关闭后不自动播放。只读身份没有抓拍、录像、隐私修改权限。

## 代码与素材

- `src/mock/MockVideoPlayer.vue`：Mock控制、能力提示、生成/保存交互与离开确认。
- `src/mock/video-provider.js`：固定本地素材提供器，每次播放重新检查授权上下文。
- `src/mock/video-service.js`：模拟厂站/对象/能力/隐私检查及显式隐私上报。
- `src/mock/video-capture.js`：Canvas抓拍、MediaRecorder、60秒/50MB限制及释放。
- `src/mock/assets/synthetic-monitor.webm`：自生成六秒无声片段；生成脚本 `scripts/browser/generate-mock-video.js`。只用Canvas，不请求摄像头或麦克风。
- `src/mock/spatial-service.js`、`transport.js`：生成资料复用内存事务，提交时重新检查权限、设备与隐私，不创建新后端接口。
- `src/views/video`、`MaterialsView.vue`：Mock播放器接入及资料来源显示；正式模式保留原关闭行为。

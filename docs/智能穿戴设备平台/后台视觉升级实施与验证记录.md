# 后台视觉升级实施与验证记录

日期：2026-09-20；方向：第一版“浅色装备展厅”。交付为后台 Mock 全局视觉升级，不是新增业务阶段。

## 范围与实现

仅改原PC的admin-mock视图、样式、本地素材、专属测试/脚本/文档及截图忽略项；不改业务服务规则，不改另一前台、后端、数据库、账号或设备。沿用六菜单，接入配置及审计仍为占位。原工作台一号站36资产、17可领、12有效领用、3活动维修口径保持。

样式分为 tokens/base/shell/components/pages，由原 styles.css 导入。统一冰白、深蓝、科技蓝、电光青、紫及琥珀；实底表单与表格保障阅读，展示区使用本地渲染图。设备档案和人员装备卡使用对应帽/带/表示意，未添加健康或厂家能力。

共九张WebP约425KB：登录主场景、工作台装备横幅、三件独立产品、人员/维修/授权主题、共用状态插画。PNG生成原稿保留在源码，页面仅引用WebP。来源和用途见 `src/admin-mock/assets/visual/README.md`。图片没有界面文字，数据仍由原Vue逻辑生成。

## 验证结果

- 原227项逻辑测试通过；增加素材、样式分层/动效/焦点、主要色对对比度3项，合计230项通过。
- Mock专用lint通过。原测试入口与Mock测试入口最终均为230项通过。新增测试曾被原Vite配置的动态URL转换误识别，已改为Node文件检查并复跑，不属于业务运行失败。
- 正式、预发布及Mock构建通过；正式/预发布有既有大包警告，不在本轮升级依赖或拆包。
- 原完整lint阻塞：原有 `@typescript-eslint` / `ts-api-utils` 的 `Intrinsic` 读取错误；未通过，不升级绕过。
- 开发模式A0–A5主流程浏览器回归通过，三种桌面尺寸；开发网络只有同源资源与Vite HMR，不连接真实业务。
- Mock预览A0–A5主流程回归通过，无业务请求、外部素材、媒体、Agora或WebSocket。
- 全页视觉脚本27组、三种尺寸；检查横向溢出、弹窗宽度、缺图、页面异常及网络边界。
- A2长文本、A3/A4/A5边界浏览器脚本通过：覆盖90字符编号、长候选、独立记录分页、失败输入、焦点恢复、切站竞态、会话失效与安全返回。最终Mock构建后全页预览再次通过，零页面错误、零WebSocket。
- 正式产物文本及文件检查未发现新增Mock素材名称、后台Token或Mock命令特征。预发布使用同一正式入口。

## 修复与限制

修复登录主图覆盖标题、横幅设备裁切、台账操作列拥挤；加深青色正文以通过主要色对4.5:1检查。没有添加持续背景动画，减少动态效果时关闭过渡。

截图：原PC `output/playwright/admin-visual` 与 `admin-a0` 至 `admin-a5`。详细样稿并排对照、检查清单及有意差异见原PC根目录 `design-qa.md`。未保存完整逐页改造前截图；不声明具备全系统前后像素差异记录。色对单测不是屏幕阅读器或整站WCAG认证。

## 使用与复验

在 `pc前端代码/melhat_pc-main` 执行 `npm.cmd run dev:mock`，打开 `http://127.0.0.1:5181`。预览：`npm.cmd run build:mock` 后 `npm.cmd run preview:mock`，端口5182。无需后端。

现有Playwright CLI打开本地页面后执行 `scripts/admin-a0-browser.js` 至 `admin-a5-browser.js`；全页截图用 `scripts/admin-visual-browser.js`。长文本/边界使用现有a2-longtext、a3-edge、a4-edge、a5-edge脚本。不应在真实入口运行Mock办理脚本。

业务仍只保留页面内存，刷新恢复种子，演示身份不是真实认证。前后台Mock不自动同步。真实权限、通知、设备接入、维修资质、持久化和生产安全未由本次视觉回归验证。

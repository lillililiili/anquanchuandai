# S3 视频监看：页面、播放器与只读接口基础

实施日期：2026-09-17。共用现有后端，沿用 Vue 3 / JavaScript / hash 路由。本文不是部署记录，也不代表真实视频、设备或媒体权限验收。

## 1. 已落地范围

- F04 `/video`：深蓝视频墙，1+7、2×4、3×3；授权筛选、分页、所选设备、底部设备条和独立详情。未接入与空设备明确区分，不使用现场示例照片。
- F08 `/video/:deviceId`：监看面板、禁用控制栏、设备元数据、人员/三类装备/作业/位置/事件/资料分区和远程指导占位。人员关联有证据且授权后可进入 F03；轨迹链接只传厂站与设备。
- 新增精确依赖 `mpegts.js@1.8.2`，仅更新新前台 package.json/package-lock.json。未使用旧 flv-extend 包装器，不改旧 PC 工程依赖。
- `src/utils/video-player.js` 独立播放器生命周期；`video-adapters.js` 原生媒体与 FLV 适配器；`media-provider.js` 正式来源默认关闭。播放器与页面没有模拟登录、演示开关、URL query 拉流或生产回退数据。
- `PortalVideoController` 两个 GET 接口，`PortalVideoService` 聚合校验，`PortalVideoSource` 来源扩展点，`PortalVideoConfiguration` 条件默认未接入实现。没有新增写接口或表。

UI 以 PDF F04/F08 为布局依据，沿用原框架色彩和导航。依据 UI/UX 生命周期、焦点和错误反馈指引，使用原生按钮/标签、可见状态文字、显式禁用原因、卸载清理；不将 PDF 示例状态作为业务事实。

## 2. 路由与查询

| 路由 | 合法 query |
| --- | --- |
| `/video` | siteId、selectedId、keyword、areaId、workId、pageNum、pageSize、layout |
| `/video/:deviceId` | siteId、returnTo（仅合法视频墙地址） |

layout 值 `1+7`（默认）、`2x4`、`3x3`。页面默认每页 8 台，3×3 切换为 9 台。服务端允许 pageSize 1–100、pageNum 1–2147483647；超大页返回空 items，但不改变真实总数。字符串 ID 满足 `[A-Za-z0-9_-]{1,64}`，不可转 Number。keyword 最长 100 字符。

登录恢复会清理非法 query。人员详情返回地址支持合法视频墙/单路地址；外部或不支持的 returnTo 不可跳转。顶栏切厂站回视频墙并清理旧选择/筛选。详情、列表使用 S1 的 AbortController 与版本标识；注销/账号变化立即使上下文失效并销毁页面资源。

第一台当前页授权设备可以自动成为选中设备，但不自动播放。设备条没有第二套播放器。轮播默认关闭，显式开启后每 30 秒只改变当前页选中设备；手动选择、查询、布局、厂站、隐藏和卸载均停止轮播。

## 3. HTTP 契约

前缀 `/api/portal/v1`，保持旧接口不变。

| 接口 | 参数 | 返回 data |
| --- | --- | --- |
| `GET /video-sources` | 必需 siteId；可选 keyword、areaId、workId、pageNum、pageSize | VideoPage |
| `GET /video-sources/{deviceId}` | 必需 siteId | Detail |

每次请求要求登录、`portal:video:read` 和授权厂站。厂站授权只来自 S1 PortalSource.context；不将部门树、sys_user、设备绑定当作厂站/人员来源。源接口 visible 逐项验证 actor/site/kind/object/permission；不可见设备不进入分页、详情或统计。区域与作业筛选不支持但传入非空值时返回 `400 FILTER_NOT_SUPPORTED`，非法/重复/未知参数 `400 VALIDATION_ERROR`。

HTTP 401/403/404/503 与 envelope.code 保持一致。403 为厂站/模块拒绝，404 `OBJECT_NOT_FOUND` 为设备不存在或不可见，503 `SOURCE_UNAVAILABLE` 为来源错误或不完整的授权证据。错误包含 requestId；无原始异常、凭据或存储信息。

统一封装示例：

```json
{
  "code": 200,
  "msg": "成功",
  "errorCode": null,
  "requestId": "服务端生成UUID",
  "asOf": "2026-09-17T00:00:00Z",
  "data": {
    "state": "NOT_INTEGRATED",
    "reasonCode": "VIDEO_NOT_INTEGRATED",
    "items": [],
    "total": null,
    "pageNum": 1,
    "pageSize": 8,
    "scope": { "siteId": "已授权厂站ID" },
    "filters": {
      "areas": { "state": "NOT_INTEGRATED", "data": null, "reasonCode": "SOURCE_NOT_INTEGRATED" },
      "works": { "state": "NOT_INTEGRATED", "data": null, "reasonCode": "SOURCE_NOT_INTEGRATED" }
    },
    "statistics": { "state": "NOT_INTEGRATED", "data": null, "reasonCode": "STATISTICS_NOT_INTEGRATED" }
  }
}
```

以上只是文档结构示例，不是运行时种子数据。默认授权来源为空时，在读取视频来源前即被厂站授权拒绝；前台没有厂站时不发起视频查询。

### VideoDevice 字段

| 字段 | 来源及规则 |
| --- | --- |
| deviceId / siteId / deviceCode / name / type | 来源主数据；type=HELMET/BELT/WATCH；ID 字符串 |
| areaId / workId | 经范围校验的筛选关联；缺失 null；详情设备对象不直接暴露这两个摘要标识 |
| communication | S1 通信结构；ONLINE/OFFLINE/UNKNOWN/NOT_INTEGRATED；旧本地快照强制 UNKNOWN |
| video | S1 Capability：SUPPORTED/UNSUPPORTED/UNKNOWN 与 VERIFIED/UNVERIFIED 分开 |
| streamState | UNKNOWN/NOT_STARTED/REPORTED_ACTIVE/INTERRUPTED，均为来源报告，不是浏览器播放状态 |
| sourceTime / freshness | UTC 源时间及来源新鲜度；无源时间不能判断 FRESH/STALE；不借用数据库更新时间 |
| unavailableReason | 本轮强制 MEDIA_ACCESS_NOT_ENABLED，不能由来源解锁播放 |

通信时间、设备视频元数据时间、实际画面源时间是不同字段。页面不会把视频元数据 sourceTime 当作拍摄时间。带、表无协议时能力保持 UNKNOWN/UNVERIFIED，不生成其定位、电量、传感或告警数据。

### 统计证据

VideoPage.statistics 为独立 Section，AVAILABLE 时包含 devices、available、interrupted、notStarted、sourceTime；未接入时所有统计通过 data=null 表达未知。

PortalVideoSource.statistics 返回仅服务端使用的 StatisticsEvidence：完整过滤授权范围的 deviceIds 与来源确认的 availableIds/interruptedIds/notStartedIds，以及源时间。服务层验证 deviceIds 与完整授权列表一致，分类集合互斥且均在授权范围内；随后以集合基数输出统计。没有该独立证据不从列表补算。该接口不是将当前分页数当视频总数，也不将通信在线推定为视频可用。

### 独立关联 Section

Detail 包含 device 与 person、equipment、works、location、events、materials 六个 Section，各自为 AVAILABLE/NOT_INTEGRATED/UNAVAILABLE/FORBIDDEN。

| Section | 额外权限 | 对象范围 kind |
| --- | --- | --- |
| person | portal:person:read | person |
| equipment | portal:person:read | equipment |
| works | portal:work:read（后续模块，S3 不授予） | work |
| location | portal:location:read | location |
| events | portal:event:read（后续模块，S3 不授予） | event |
| materials | portal:material:read | material |

Related 采用固定安全字段：id/siteId/name/type/sourceTime/receivedAt/freshness/attribution/evidenceId，无开放扩展 Map。attribution 必须 CONFIRMED 且有 evidenceId，再逐对象检查可见性。证据缺失或无法证明历史归属时不返回关联摘要；仅当前绑定不能作为历史证据。装备 type 对应 HELMET/BELT/WATCH，未知关联不显示“未领用”；资料 type 对应原始资料类型，sourceTime 为采集时间，receivedAt 为接收时间，不包含访问地址。

分区 UNAVAILABLE 保留本分区错误，不降级为空；整来源抛异常仍返回 503。无分区权限直接 FORBIDDEN/data=null。来源实现需按调用者生成新 DTO，不能复用跨账号可变对象。

## 4. 播放器状态与释放

独立状态：NOT_INTEGRATED、UNSUPPORTED、IDLE、CONNECTING、PLAYING、BUFFERING、PAUSED、INTERRUPTED、ERROR、FORBIDDEN。

- `play()` Promise 成功仅表示请求获准。媒体 playing 事件后，requestVideoFrameCallback 的 mediaTime 前进才转 PLAYING；浏览器不支持该 API 时以 readyState 和 currentTime 前进作为兼容观察。
- waiting/stalled/ended/error 改变状态；技术观察窗口 5 秒无画面推进显示“本机画面未推进”，不推定设备离线。这是本机播放器超时，不是厂家业务阈值。
- 显示 device sourceTime 与本机 lastDisplayedAt 两条时间；独立媒体测试无源时间始终 null。
- 不自动重连；start/retry 重新调用 provider.acquire(context, signal)。异步返回带版本判断；迟到媒体来源释放后丢弃。
- pause 与页面隐藏释放流、适配器、监听器、定时器和帧回调；恢复页面不自动播放。destroy 幂等，局部清理失败也继续执行其他释放步骤。
- mpegts.js 动态加载，只有未来经审查媒体 provider 返回授权来源后才可能执行。正式 provider 不返回任何地址，页面不执行 start，也没有远程媒体会话端点。
- 全屏只放大监看面板，不代表建立拉流；全屏拒绝给出文字提示。

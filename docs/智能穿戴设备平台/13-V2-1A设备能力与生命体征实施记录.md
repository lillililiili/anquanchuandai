# V2-1A：设备能力与人形生命体征

实施日期：2026-09-18；收尾验证日期：2026-09-19（本机时区，UTC为09-20）。本轮只修改新前台、测试与文档，不修改原PC、安卓、后端、数据库、账号或依赖。既有工作区中的后端/原PC修改保留，非本阶段产生。

## 实现内容

- 保留七菜单、现有路由、Mock内存及领用闭环。新增型号声明、实例配置、接入状态、真机验证、隐私报告和专属观测。
- 人员装备、装备详情、视频元数据从同一设备配置派生能力；不再把安全帽一律视为支持视频。领用状态、设备通信和业务能力互不替代。
- 安全帽详情展示穿戴报告与CPU温度（非体温）；安全带展示需求模拟的锁扣、单钩、姿态、静默/跌落报告与设备工作时长，显式说明非安全判断。
- 人员独立详情与手表详情复用本地SVG人形面板，青蓝轮廓、底部光环、两侧体征；人员列表右侧为紧凑摘要。没有外部素材请求、3D依赖、假心电图或随机跳数。
- 四类候选指标为心率、血氧、体温和血压。固定读数为界面合成样例，不是厂家能力或健康结论。无权限、错误、未接入、未知和过期独立表达。
- 观测集合独立于当前领用关系，记录测量时的人员及关系证据；转领不迁移观测、不生成新读数。手表页明确历史归属，当前人员只读取当前关系有证据的观测。
- 修正人员详情直接跨厂站链接的上下文同步，授权通过后才读取，退出/切站/迟到响应清理沿用统一查询生命周期。

## 字段与契约

旧18个只读查询及装备服务保持兼容。新增字段是可选扩展，正式接口没有这些字段时显示待确认。

| 对象 | 字段与规则 |
| --- | --- |
| 设备profile | model、firmware（当前未知）、sourceKind、privacy、capabilities、observations；模拟配置不写入真实能力 |
| 能力 | declaration=DECLARED/OPTIONAL/NOT_DECLARED/CONFLICTING；installation=PRESENT/ABSENT/UNKNOWN；integration=MOCK_READY/NOT_INTEGRATED；verification=UNVERIFIED；evidence保留文档依据 |
| 兼容能力 | 原SUPPORTED/UNSUPPORTED/UNKNOWN按明确合成实例装配派生，不按资料遗漏推断厂家不支持；详细分区始终说明模拟配置 |
| 观测 | observationId/siteId/deviceId/personId均为字符串；assignmentId/evidenceId证明观测归属；metric/value/unit、sourceTime/receivedAt、freshness、sourceKind分别保存 |
| 血压 | value为两项数组，按收缩压/舒张压展示；缺失为null，不设健康阈值 |
| 可用性 | AVAILABLE、EMPTY、NO_WATCH、UNKNOWN、NOT_INTEGRATED、FORBIDDEN；来源异常抛503而非空结果 |

`@vitals-provider`构建期选择来源。仅Mock分发器处理 `GET /api/portal/v1/vitals`，参数为siteId以及personId/deviceId二选一；不接受其他筛选。经身份、模块和对象范围检查、统一200毫秒可取消延迟、会话代次校验，响应经过独立契约检查。403/404/503保留requestId。此路径不通过HTTP发送，不新增后端Controller。正式/预发布/数据库demo提供器直接返回未接入，不访问猜测接口。

能力判定必须同时考虑实例配置、来源、运行隐私、模式、权限和阶段开放情况。本阶段能力说明不启用视频、录制、通信或设备控制。该公共判断可供V2-3/V2-6复用，但不声称完成后续业务。

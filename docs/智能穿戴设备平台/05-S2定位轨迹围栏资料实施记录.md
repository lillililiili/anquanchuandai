# S2 定位、轨迹、围栏与现场资料：只读基础

## 交付边界

本阶段交付页面、契约、只读接口及隔离测试，不代表真实人员、定位或真机验收通过。没有修改原 PC、安卓、数据库、账号、注册开关、设备配置及旧接口。本轮开始前原仓库的未提交改动全部保留；Portal 包和新前台在原基线中也是未跟踪文件，不能用根目录 `git diff --stat` 判断新增代码数量。

新前台沿用 Vue 3 / JavaScript / hash 路由及九个菜单，只增加精确依赖 ol@7.5.2。旧工程技术栈没有升级。默认无底图网络请求，也没有复制旧工程的底图服务地址或密钥。

## 公共响应、参数与错误

前缀 `/api/portal/v1`，全部 GET，所有新增接口必须传 `siteId`。标识是 1-64 位字符串，仅字母、数字、下划线、连字符。长数字 ID 必须是 JSON 字符串，不经过 JavaScript Number。

| 接口 | 参数（除 siteId） | 返回 data | 权限 |
| --- | --- | --- | --- |
| /devices | keyword、pageNum、pageSize | Page<DeviceOption> | location/track/material 的 read 权限至少一个，并按相应目的过滤对象 |
| /locations/latest | keyword、pageNum、pageSize | Page<LocatedDevice> | portal:location:read |
| /tracks | deviceId、from、to 必填；personId 可选 | Section<Track> | portal:track:read |
| /fences | status、keyword、pageNum、pageSize | Page<Fence> | portal:fence:read |
| /fences/{id} | 无 | Fence | portal:fence:read |
| /materials | deviceId、personId、type、from、to、keyword、pageNum、pageSize | Page<Material> | portal:material:read |
| /materials/{id} | 无 | Material | portal:material:read |

分页默认 pageNum=1、pageSize=20，最大 pageSize=100。keyword 最长 100 字符，对来源 name/id 做包含匹配。重复参数和非白名单参数返回 400。type 为 PHOTO/VIDEO/AUDIO；status 为 ENABLED/DISABLED/UNKNOWN。时间使用 ISO8601 UTC、Z 后缀；from/to 必须成对且前者小于后者，首版查询边界包含两端。时间未知保持 null；接口 asOf 只是服务器查询时间。

```json
{
  "code": 200,
  "msg": "成功",
  "errorCode": null,
  "requestId": "每次响应生成的请求标识",
  "asOf": "2026-09-17T02:00:00Z",
  "data": {
    "state": "NOT_INTEGRATED",
    "reasonCode": "LOCATION_NOT_INTEGRATED",
    "items": [],
    "total": null,
    "pageNum": 1,
    "pageSize": 20,
    "scope": { "siteId": "synthetic-site" }
  }
}
```

示例仅说明结构，不是默认运行数据。已接入空结果使用 AVAILABLE/items=[]/total=0；未接入 total=null。轨迹使用 Section，AVAILABLE 时 data 为 Track，未接入时 data=null。详情不存在或不可见返回 404，不提供一个虚构的空对象。

错误：400 VALIDATION_ERROR；401 UNAUTHENTICATED；403 FORBIDDEN；404 OBJECT_NOT_FOUND；422 RESULT_TOO_LARGE；503 SOURCE_UNAVAILABLE。错误带 errorCode/requestId，不暴露底层异常。兼容现有认证过滤器的 HTTP200/code401 和 HTTP401。取消请求不显示失败提示。未知接口内部异常仍是通用 500，不伪装为空数据。

## 字段及来源要求

所有对象包含 id/siteId/name。DeviceOption 增加 type（HELMET/BELT/WATCH）及 deviceCode；只提供台账类型，不由类型推定传感能力。

LocatedDevice：deviceId、deviceCode、personId/personName、attribution、communication、position。人员字段必须有 CONFIRMED 证据并通过对象范围校验，否则清空并标 UNKNOWN。设备通信状态与位置质量/时效独立。

Position：longitude/latitude、coordinateSystem、source、sourceTime、receivedAt、quality、freshness。绘图必须同时满足 WGS84、quality=VALID、经纬度为有限数、经度绝对值<=180、纬度处于 Web Mercator 可显示范围（绝对值<=85.0511287798）；0,0 是合法值。未知/不支持坐标系不转换不落点。无源时间或未来源时间不能标 FRESH/STALE。未指定新鲜度业务阈值，由有依据的来源提供，页面不自行设定离线或过期阈值。

Track：deviceId、可选 personId/attribution、from/to、complete/incompleteReason、segments、gaps。segment 含 segmentId、continuity（CONFIRMED/UNKNOWN）、points；gap 含 from/to/reason。来源必须保证时序、范围和历史归属，不能把当前绑定补到历史点。personId 查询无法证明完整历史归属时返回 HISTORICAL_ATTRIBUTION_UNKNOWN。无效点、无源时间点、不同片段和明确缺口都打断连线。播放按实际有效采样点序列每秒一步，倍速是步进频率，不模拟实际速度；无时间点不参与播放。隐藏页面暂停，离开页面释放定时器。

轨迹超过 10000 个源点返回 422，要求缩小区间；这是前台保护性容量上限，不是设备业务阈值。不静默裁剪。来源确实仅返回部分结果时 complete=false 且必须提供 incompleteReason，页面显著提示。来源不能先截断再声明 complete=true。

Fence：status、coordinateSystem、ring（闭合经纬度数组）、rule、version、sourceTime、effectiveAt。未知范围不绘制；更新时间不充当生效时间；首版不计算围栏进出事件、不提供写入端点。

Material：type、deviceId/deviceCode、source、capturedAt、receivedAt、personId/personName/attribution、workId/workAttribution、eventId/eventAttribution、accessReason。每类关联分别需要证据及可见性；未知归属不得由当前绑定补全。accessReason 固定 FILE_ACCESS_NOT_ENABLED。DTO 没有 fileUrl、previewUrl、存储路径或 token；前端也拒绝地址字段。下载与存储代理必须在后续单独设计对象鉴权、允许的存储来源、内容类型及审计后才能开启。

## 数据源接入点及权限

后端 PortalS2Controller → PortalS2Service → PortalSpatialSource / PortalMaterialSource；授权厂站仍来自 S1 PortalSource.context(actorId)。S2 配置提供 ConditionalOnMissingBean 默认未接入实现，不查询数据库、设备或存储。

接入时替换来源 Bean，返回每次请求独立 DTO（服务层会清理不可靠关联和时效），不能复用可变缓存对象。来源必须在 actor/site/permission 下查询，并实现 visible 检查；列表只可返回完整候选集合，服务层再次过滤可见对象、条件筛选、排序和分页。不能先从设备平台取一页，再把当前页长度作为总数；规模增长后应明确升级来源为受控分页契约，不可静默改语义。

材料关联的设备可见性由 PortalMaterialSource 独立确认；设备选择器来自 PortalSpatialSource，二者必须采用一致授权映射。设备列表可以因轨迹权限可见，但在资料用途下仍被拒绝，这是按用途授权，不是自动获得全部模块权限。

Context 兼容增加 devices/locations/tracks/fences/materials 能力，默认 UNKNOWN/SOURCE_NOT_INTEGRATED；正式连接器只有确认接入和验证后才能更改能力声明。S2 权限只参与校验和上下文返回，本阶段不自动分配。

前端共用 useS2Workspace/usePortalQuery，route query 保存合法筛选、分页和选中对象；参数变化中止旧请求，并用版本号阻止旧响应覆盖。列表改变清空详情；厂站选择同步顶栏，切厂站清空旧筛选和选择。VectorMap 每个容器独立实例，不加载底图，尺寸变化重算展示范围，卸载释放地图、观察器和图层。

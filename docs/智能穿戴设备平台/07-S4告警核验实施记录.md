# S4 告警与现场核验：实施与契约

日期：2026-09-17。交付口径为“页面与接口基础”，不是核验业务闭环或真机验收。

## 页面及代码入口

- F13 `/alarms`：阶段统计、设备编号/时间/来源类型/阶段筛选、事件分页及右侧独立摘要。初始不选择，行点击或事件编号按钮键盘选择；筛选、分页、厂站变化清理选择。
- F12 `/alarms/:eventId/verification`：事件事实、关联人员/负责人/作业、事件位置、历史与当前装备、资料元数据、事实时间线、已有核验记录及原系统状态。时间线和核验记录独立分页，页面每页 5 条。
- 页面在 `src/views/alarms`，复用组件在 `src/components/events`，样式在 `src/styles/events.scss`。沿用 PDF F13/F12 的深蓝框架、左主区右摘要/核验区，不复制设计中的照片、人员或统计。
- `src/utils/event-contract.js` 校验身份、分页、分区、时间和敏感字段；`event-route.js` 处理 query、安全返回和时区；`src/api/events.js` 为五个 GET；`useEventWorkspace` 复用认证、上下文和取消/版本检查。
- query 仅保留 siteId、keyword、from、to、eventType、phase、pageNum、pageSize、selectedId。详情保留合法 siteId/returnTo；非法或外部返回目标回退 `/alarms`。保留九个菜单及 hash 路由。
- 时间输入按厂站 IANA 时区转为 UTC，时区缺失/无效明确采用 UTC。区间为 `[from,to)`；夏令时不存在或重复的本地时间拒绝提交，不静默猜测偏移。

## 旧链路核查与复用边界

旧 `RealTimeAlarmController → IRealTimeAlarmService / RealTimeAlarmServiceImpl → RealTimeAlarmMapper` 保持不变。`/hat/alarm/page` 使用 current/size 和 `R<IPage<RealTimeAlarm>>`，不能套用新 items/total，也不能把 unhandled-count 当新平台阶段统计。

旧 handle 修改处理状态；answer 当前实现仅在条件成立时返回成功，不能证明建立通话或完成认领；receive 写入报警并设置本机时间；delete 为逻辑删除。S4 不调用这些接口。

旧控制器未直接声明方法级权限；全局 SecurityConfig 末尾要求认证，不能据此推定已有完整对象/厂站授权。新接口单独通过 PortalAccess 和来源可见性检查权限，不能依靠隐藏菜单。

`PortalLegacyAlarmAdapter` 是无 IO 的纯字段映射：需要显式平台事件 ID 和已确认厂站 ID；保留旧 ID 为 sourceEventId，来源系统标识为 LEGACY_HELMET。alarmType/alarmLevel/isHandled 分别保留为 rawType/rawLevel/legacyHandled，phase/eventType 默认 UNKNOWN；不从 userName 或当前绑定创建历史人员关系。不以 updateTime 补 occurrence/received 时间，且不把 receive 设置的服务器时间自动认定设备源时间。该映射器未接入默认来源。

## 新只读 API

前缀 `/api/portal/v1`，共享现有后端，不新增工程。

| GET | 参数 | 结果 |
| --- | --- | --- |
| `/events` | siteId；keyword、from/to、eventType、phase；pageNum/pageSize | EventPage，含 filters |
| `/events/summary` | siteId 及与列表相同筛选，不接受分页 | Section<Statistics> |
| `/events/{eventId}` | siteId | Detail，事件事实及独立 Section |
| `/events/{eventId}/timeline` | siteId、pageNum/pageSize | Page<Timeline> |
| `/events/{eventId}/verifications` | siteId、pageNum/pageSize | Page<Verification> |

所有请求必须登录、持有 `portal:event:read`，并通过授权厂站检查；核验记录额外要求 `portal:event:verification:read`。分页默认 20、上限 100；未知/重复参数、非法枚举/时间/分页返回 400。不支持的非空筛选返回 FILTER_NOT_SUPPORTED。未授权厂站 403，不存在或不可见事件 404，来源异常或证据结构冲突 503 SOURCE_UNAVAILABLE。

沿用 Envelope：code、msg、errorCode、requestId、asOf、data。asOf 是响应时间，不是事件或设备时间。ID 一律字符串，时间为 UTC ISO8601，缺失为 null。Page 使用 state、reasonCode、items、total、pageNum、pageSize、scope；未接入 items=[]、total=null，已接入空结果 total=0。时间排序按 Instant 比较，支持不同小数精度。

身份分离 eventId 与 sourceSystem/sourceEventId，来源对相同但平台身份冲突会拒绝；不同来源同编号不会合并。统计要求独立来源提供同筛选、同授权范围完整的事件 ID→阶段证据，校验与可见事件集合一致后计数；不从当前页补算。缺统计来源保持未接入。

## 字段与状态

| 领域 | 表达 |
| --- | --- |
| 本地跟进 | UNCLAIMED / PROCESSING / AWAITING_VERIFICATION / LOCAL_COMPLETED / UNKNOWN |
| 核验记录 | DRAFT / SUBMITTED / UNKNOWN；草稿不允许有 submittedAt |
| 两类回传 | 各自独立 NOT_CONFIGURED / PENDING / SENDING / SUCCESS / FAILED / UNKNOWN |
| 事件事实时间 | occurredAt、receivedAt、sourceUpdatedAt 分别保留；无源更新时间 freshness=UNKNOWN |
| 关联关系 | id、siteId、attribution=CONFIRMED、evidenceId；缺证据未知，不回填当前绑定 |
| 装备快照 | HISTORICAL / CURRENT / UNKNOWN，当前状态明确“不代表事件时状态”；带、表能力待确认 |
| 证据元数据 | id、name、type、version、digest、capturedAt、receivedAt；没有文件地址 |
| 核验字段 | conclusion、scene、measures、submittedAt、version、evidence；只读不存浏览器草稿 |
| 原系统 | sourceSystem、sourceEventId、status、sourceTime，独立于平台跟进 |

“无法确认”不改变跟进阶段；回传成功不代表本地完成；isHandled 不等于已核验或原系统结案。不会由通信、电量或位置自行生成穿戴告警。

人员/负责人用人员权限，装备使用人员装备读取权限，位置/视频/资料/作业各用对应模块权限，随后检查来源对象范围。核验回传分区同时检查核验权限；证据仍需资料权限。无权分区清空 data，不返回摘要。事实与时间线的自由文本必须在来源层按调用者授权脱敏。

地图仅使用有事件关联证据的 WGS84 有效坐标，零坐标有效，无外部底图。视频链接明确为当前设备监看而非事件录像，播放器仍关闭。文件只展示授权元数据，没有原图、播放、下载或上传。

## 来源扩展点和下一步门槛

后端 portal 包新增 PortalEventController、PortalEventModels、PortalEventQuery、PortalEventService、PortalEventSource、PortalEventConfiguration、PortalLegacyAlarmAdapter；Context 扩展 events/verifications 能力。默认来源不查询旧报警表、设备平台、存储或外部系统，visible 默认 false。

接入方应返回每次请求新建、已授权、已脱敏的 DTO，以及完整集合（不是预分页集合）。当前基础服务在内存筛选/分页，真实大数据来源接入前需评估数据库下推分页和快照一致性；不可静默截断。统计和列表快照不一致时拒绝输出统计，不输出看似可靠的数量。

真实联调需确认测试账号、权限、厂站映射、事件身份、类型/阶段规则、时间规范和历史归属证据。认领/转交/草稿/提交/证据上传另需持久化、并发版本、事务、幂等、审计和受控存储方案；本轮没有这些写接口、迁移、配置或模拟成功。

验证结果见新前台 `S4-VERIFICATION.md`。账号创建继续暂缓；没有部署或重启当前后端。

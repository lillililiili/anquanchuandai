# PC 后台布局改造记录

## 分析与范围
当前服务 5181 为 src/admin-mock 的独立管理入口。Vue 3.5.12、Vite 5.4、Pinia 2、Vue Router 4；Element Plus 2.2.27 与其图标已安装。后端 pom 标明若依 3.8.5。当前管理页主要为原生 HTML 控件，沿用现有查询、表单与权限提供器，借用现有 Element Plus 浮层用于更多操作，保持原 PC 入口隔离。

## 页面清单
| 模块 | 页面与状态 | 改造重点 |
| --- | --- | --- |
| 框架 | 登录、顶栏、侧栏、功能页签、401、404、legacy | 紧凑导航、简洁标题、统一状态 |
| 工作台 | 指标、最近变更、6 类指标抽屉 | 去装饰、明细逐字段拆列 |
| 装备 | 设备台账、设备详情、新增/编辑设备 | 设备编号/名称/SN/类型/型号/区域/使用状态/领用/通信/身份核验独立列 |
| 领用 | 当前领用、归还记录、全部流水、人员/设备历史、领用与归还面板 | 人员与设备信息、日期、动作分列 |
| 维修 | 运维设备、维修工单、使用状态记录、工单详情、运维面板 | 不同标签页独立列定义 |
| 主数据 | 人员、组织、区域、厂站、班次、账号、角色 | 按实体定义字段列，更多操作，新增/编辑/详情/影响确认 |
| 人员详情 | 基础信息、三类装备、领用流水 | 业务分组、说明与字段对齐 |
| 协助组 | 列表、档案、成员终端、配置历史、编辑及启停 | 编号/名称/状态/策略分列，多值内容保留详情 |
| 接入 | 六类连接器、连接设置、同步任务、预览/确认、演示参数 | 统一表单与列表密度 |
| 审计 | 列表、导出、详情/差异 | 时间/编号分列，差异单行与完整快照 |

## 统一规范
- 主题沿用企业后台蓝灰色：主色 #006bff，正文 #102652，辅助 #637695，边框 #e1e7f0，页面底色 #f3f7fc。
- 侧栏 200px / 折叠 64px，顶栏 56px；内容区 24px，区块间距 16px，圆角 4px。
- 正文/控件 14px，表格正文 15px、表头 14px，行高 48px；表格操作按钮 30px。
- 标题说明 → 查询 → 操作工具栏 → 表格 → 分页；筛选字段宽 200px，控件高 36px。
- 表格一格一字段，长文本单行省略并保留 title；数字右对齐，状态/操作居中，时间统一 UTC（班次保留厂站时区）。表格内部横向滚动，不压缩字号。
- 表单 16px 间距，两列宽字段占整行；弹窗内部滚动，取消在前、提交在后。
- 不改变任何后端、接口、数据提供器或业务权限；无新增排序/批量删除等原本不存在的能力。

## 实施与验证
已完成当前 5181 独立后台入口的公共框架及各业务模块改造。原 PC 业务入口不在该后台路由树内，保持隔离，未宣称对旧入口完成视觉验收。

### 实际访问范围
- 登录、工作台及资产指标抽屉；设备台账、设备详情、新增与编辑；人员及人员详情。
- 组织、区域、厂站、班次、账号、角色列表；上述主数据新增表单、角色详情、账号编辑与授权影响预览。
- 当前领用、归还记录、全部流水；人员历史、归还表单；运维设备、维修工单、使用状态记录、工单详情和运维表单。
- 协助组列表、详情、编辑；连接器列表、设备同步设置、任务预览及确认窗口；六类连接器路由均已访问，但没有逐一执行每类同步流程。
- 演示参数、审计列表与差异详情；401、404 和旧入口占位页。
- 空厂站、审计员只读角色、禁用操作说明、必填校验。

### 功能与尺寸验证
- 浏览器实际执行：查询、重置、人员翻页；本地设备新增及修改；归还并生成流水；账号普通字段保存；同步任务预览；审计导出成功提示。授权预览未确认变更，导入确认未提交。
- 两档桌面尺寸检查：小档实际 CSS 宽 1366px，高 767/769px（浏览器缩放导致目标 768px 上下 1px）；大档 1920×1080，部分初轮记录为 1922×1081，后续主页面使用准确 1920×1080 复查。
- 已记录的表格正文 15px、行高约 48px，无 td 内 small/br 多字段堆叠、表头与行列数不一致或页面横向溢出。多列仅在表格区域滚动，关键列和操作列固定。
- lint:admin-mock 通过；test:admin-mock 11 个文件、296 项通过；build:mock 通过；git diff --check 通过。浏览器最后检查未记录 error 日志。
- 已刷新验收专用页面恢复原始本地种子数据；未更改后端或数据库。

### 覆盖边界与仍需验证
- 当前入口显示“服务未接入”，使用项目原有本地内存提供器；本轮不代表真实后端、真实设备或生产业务验收。
- 未逐一验证全部指标抽屉的数据分支、每种角色组合、每条启停/删除/凭据重置路径以及网络失败重试；未访问没有当前入口的旧场景配置弹窗。共享样式覆盖这些组件，但不将其列为已实际视觉验收。
- 当前列表原本无排序入口，没有为样式改造新造排序能力；现有查询、分页、筛选与权限判断保留。
- 人员详情的组织/区域原始标识保留语义；真正多值的角色/授权范围用数量和现有详情入口呈现，未编造额外业务字段。

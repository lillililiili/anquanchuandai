# 智能安全帽平台设计规范

本规范对应 2026-09-06 已确认的视觉升级，覆盖登录页、后台业务模块、系统管理和数据大屏。

## 方向

全浅色精致商务风格。系统名称为“分体式智能安全帽平台”，面向安全监督员、调度员与设备管理员。页面强调可读性、稳定的操作位置和真实业务信息。本次不提供明暗切换。

## 色彩与排版

- 瓷白卡片 #FFFFFF，雾灰背景 #F4F7FA，品牌蓝 #1765D1，辅助青 #148B98。
- 主文字 #172B45，次文字 #52647A，边框 #E2E8F0。
- 告警、警告、正常状态保留红、黄、绿语义，不能仅靠颜色传递状态。
- 中文使用微软雅黑、苹方等本机无衬线字体，不依赖外部字体服务。正文 14px，标题 22–24px，统计数字 28–32px，数字等宽排版。
- 白色侧栏与顶栏，选中项使用浅蓝底。卡片圆角 12px，控件圆角 8px，页面间距 20–24px。

## 素材与组件

15 张独立原创素材的原图与提示词存放于 output/visual-upgrade；压缩后的页面资源位于 public/visuals。品牌标志使用安全帽与守护盾图形，统一用于登录、展开与折叠侧栏、favicon 和数据大屏。

BrandLogo 负责品牌展示；ModuleHeader 负责模块标题、说明、右侧装饰图与操作插槽；BrandedEmpty 负责暂无记录和设备未连接场景。装饰图片不叠加在输入区、表格数据、真实地图或视频上。图片加载失败时文字与操作仍须可用。

登录页桌面采用 58% 场景和 42% 表单区域，820px 以下切换单列，保留账号、密码、验证码、密码可见、回车提交和加载反馈。后台监控与轨迹使用紧凑标题，给业务内容留出空间。

## 实施约束

主题以 src/assets/styles/index.scss 中的 CSS 变量为基础，同步 Element Plus 与 settings 主色。优先整理现有规则，避免重复大范围 !important 覆盖。保留键盘焦点，支持 prefers-reduced-motion，宽表格在自身容器滚动。

不改变 API、权限、路由及业务数据结构，不增加虚构统计。对讲、广播验收不向真实设备发送消息。历史设计规范已随源文件保存在 backups/visual-upgrade-20260906-143125。

# Design Context

## Users

**Primary users:** 安全监督员 (Safety Supervisors), 调度员 (Dispatchers), 工厂管理人员 (Factory Managers)

**Context:** 监控值班室 (Monitoring Control Room) — users spend long hours monitoring multiple data streams in a dedicated control room environment, often under artificial lighting with multiple screens.

**Jobs to be done:**
- Real-time monitoring of safety helmet status and alerts
- Quick response to emergency situations (SOS, falls, fence breaches)
- Managing device fleets and user permissions
- Reviewing location history and video footage
- Coordinating field teams through voice/video intercom

**Emotional goals:** 自信可靠 (Confidence/Reliability), 专业严谨 (Professional Rigor) — users need to trust the system implicitly during critical safety moments. The interface should feel like a precise instrument, not a burden.

---

## Brand Personality

**Three words:** 专业 (Professional), 舒适 (Comfortable), 严谨 (Rigorous)

**Voice & Tone:**
- Professional but not cold — warmth through thoughtful details
- Authoritative in data presentation — precise, unambiguous
- Calm under pressure — no alarming visual noise, even during alerts
- Respectful of the user's expertise — assumes competence

**References:**
- Braun industrial design — functional precision, honest materials
- MUJI — restrained elegance, natural textures
- Modern aviation cockpits — information density handled with clarity
- Medical monitoring equipment — trustworthy, precise, life-critical

**Anti-references (AVOID):**
- Generic admin dashboard templates with card grids and icon+text patterns
- Rigid corporate "enterprise software" aesthetics
- Overly decorative or playful interfaces
- "Startup SaaS" look with gradient text and decorative elements

---

## Aesthetic Direction

**Visual Tone:** Restrained minimalism with industrial precision. The interface should feel like a well-crafted tool — the kind that gets better with use, not dated.

**Theme Strategy:**
- **Default: Dark mode** — Control rooms are dimly lit; dark interfaces reduce eye strain during long monitoring sessions
- **Light mode available** — For daytime office use, documentation, or presentations
- The theme should feel like two expressions of the same identity, not light/dark versions of different designs

**Color Philosophy:**
- Neutrals tinted toward warm stone (current MUJI direction is correct)
- Tech blue (#2563eb) as primary — conveys industrial professionalism and reliability
- Accents used sparingly: only for status indicators and critical actions
- Alert colors (success/warning/danger) follow industrial safety standards but desaturated for the UI chrome

**Typography:**
- Clean, highly legible sans-serif for data and UI
- No decorative display fonts — the content is the focus
- Consistent sizing hierarchy with clear contrast between levels

**Spatial Design:**
- Generous spacing to reduce cognitive load during long sessions
- Clear visual grouping without heavy containers
- Information density appropriate for power users, but not cramped

**Motion:**
- Subtle, purposeful — never decorative
- Fast response to interactions (optimistic UI)
- Reduced motion by default for critical monitoring interfaces

---

## Design Principles

1. **Precision over Decoration** — Every visual element must serve a functional purpose. No gradients, glassmorphism, or decorative patterns.

2. **Trust Through Consistency** — Predictable layouts and interactions build trust. Users in critical situations need to know where information lives.

3. **Comfort for Long Sessions** — Eye strain matters. Dark mode default, muted colors, adequate contrast without harshness.

4. **Industrial Honesty** — Materials and colors should feel authentic. No faux textures or artificial depth.

5. **Alert Clarity** — Emergency situations require immediate visual hierarchy. Alerts must cut through without causing panic.

## Technical Context

**Stack:** Vue 3 + Element Plus + SCSS

**Existing Design System:**
- MUJI × shadcn inspired color palette (stone neutrals + tech blue)
- CSS custom properties for theming
- Paper texture overlay for subtle warmth
- Both light and dark modes implemented

**Constraints:**
- Must work with Element Plus component library
- Chinese language interface (text density considerations)
- Real-time data updates (performance matters)
- Video streaming integration (layout must accommodate video players)

## Spacing System

**间距系统 - 4pt 基础比例尺**

### Tight Groupings (紧密分组)
| Token | Value | Usage |
|-------|-------|-------|
| `--space-1` | 0.25rem (4px) | 微调 |
| `--space-2` | 0.5rem (8px) | 紧密元素分组 |
| `--space-3` | 0.75rem (12px) | 标准元素间距 |
| `--space-4` | 1rem (16px) | 组件内边距 |
| `--space-5` | 1.25rem (20px) | 中等内边距 |

### Generous Separations (宽充分隔)
| Token | Value | Usage |
|-------|-------|-------|
| `--space-6` | 1.5rem (24px) | 区域内边距 |
| `--space-8` | 2rem (32px) | 区域间距 |
| `--space-10` | 2.5rem (40px) | 大间距 |
| `--space-12` | 3rem (48px) | 主要区域分隔 |
| `--space-16` | 4rem (64px) | 页面级间距 |

### Semantic Tokens (语义化)
| Token | Value | Usage |
|-------|-------|-------|
| `--gap-tight` | var(--space-2) | 相关元素 |
| `--gap-standard` | var(--space-3) | 兄弟组件 |
| `--gap-relaxed` | var(--space-4) | 组件组 |
| `--section-padding` | var(--space-6) | 区域容器 |
| `--section-gap` | var(--space-8) | 主要区域之间 |

### Visual Rhythm Principles
- **紧密分组**: 相关元素使用 `--gap-tight` (8px)
- **宽充分隔**: 不同区域使用 `--section-gap` (32px)
- **变化的间距**: 不要让所有间距相同，创造视觉节奏

### Utility Classes
所有间距工具类可在 `custom.scss` 中找到：
- `.gap-tight`, `.gap-standard`, `.gap-relaxed` - gap 工具
- `.section-padding`, `.section-gap` - 区域间距
- `.stack-tight`, `.stack-standard`, `.stack-relaxed` - 垂直堆叠
- `.row-tight`, `.row-standard`, `.row-relaxed` - 水平排列

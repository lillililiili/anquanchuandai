# 分体式智能安全帽平台 PC端 (melhat_pc)

分体式智能安全帽平台管理系统的PC端前端项目。主要提供对安全帽设备的管理、数据监控、实时定位、视频流预览、群组管理以及用户权限等管控功能。

## 项目功能

本系统旨在实现智联安全帽的高效管理与数据可视化，核心业务包含但不限于：

- **设备监控与控制**：实时查看在线/离线设备状态，支持指令下发。
- **定位与地图 (GIS)**：安全帽佩戴者的实时位置追踪、历史运行轨迹回放、电子围栏设置。
- **音视频监控**：支持多路实时视频流预览。
- **告警管理**：SOS报警、电子围栏越界报警、跌落报警等自动化提醒与处理系统。
- **用户与群组管理**：支持层级化的群组（部门）划分与不同角色权限（如普通成员、管理员）设定。
- **统计图表**：相关业务数据的多维可视化统计。

## 项目结构

```text
src/
├── api/             # 存放所有的接口请求模块
├── assets/          # 存放静态资源文件（如图片、图标等）
├── components/      # 全局公用组件
├── composables/     # 组合式函数 (Vue Composition API)
├── config/          # 项目相关配置文件
├── directive/       # 全局自定义指令
├── hooks/           # 通用的业务/UI相关钩子函数
├── layout/          # 页面整体布局组件（侧边栏、工具栏、导航等）
├── plugins/         # 插件配置与初始化
├── router/          # 路由配置（静态路由与动态路由生成）
├── store/           # 全局状态管理
├── utils/           # 各类工具函数与辅助方法（请求封装、鉴权等）
├── views/           # 页面级业务归属组件
└── __tests__/       # 单元测试文件所在目录
```

## 开发与运行指南

本项目默认使用 **Bun** 作为包管理和运行工具。

### 1. 安装依赖

请确保本地已经安装了 [Bun](https://bun.sh/) 操作环境，然后在根目录下执行：

```bash
bun install
```

### 2. 启动开发服务器

```bash
bun run dev
```

该命令将启动本地开发服务器，默认可通过浏览器访问项目。

### 3. 项目构建 (生产环境/测试环境)

- 生产环境构建：
  ```bash
  bun run build:prod
  ```
- 测试机（Staging）环境构建：
  ```bash
  bun run build:stage
  ```

### 4. 代码规范检查与修复

```bash
bun run lint
bun run lint:fix
```

### 5. 单元测试与代码覆盖率

```bash
# 运行单元测试
bun run test

# 运行并生成测试覆盖率报告
bun run test:coverage
```

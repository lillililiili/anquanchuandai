## 人员设备页面夹具

`tests/page-equipment.test.mjs` 在内存构造人员、设备、领用、能力及事件对象，使用 Vue 编译器和服务端渲染执行真实页面模板。子组件使用显式替身，网络依赖不访问后台。它不是生产演示模式，也不会调用数据库、设备服务或媒体服务。

| 覆盖主题 | 实际断言 |
| --- | --- |
| 仅安全带人员 | 总览、人员、作业、单路、视频墙不生成 `VideoFrame`；旧集中设备及控制面板不再挂载 |
| 离线安全帽 | 支持视频时保留视频区域；语音待联调按钮禁用；播放器不被链接元素包裹 |
| 大屏候选 | 真实安全帽不被 demo 开关排除；离线保留状态；归还后移出当前视频候选；仅带不产生候选 |
| 事件证据 | 无影像时显示证据空态；当前视频为独立区域；没有当前领用能力时不生成视频 |
| 未关联人员 SOS | 告警和 SOS 页面保留事件、设备及接警入口；位置来自 `EventLocation`，不替换为某人员当前位置 |
| 作业来源 | 计划开始时间不生成检查/到场事实；风险只从实际字段读取；无来源保持空态 |
| 围栏 | 正式模式拒绝无坐标系、百分比及未知坐标系，接受 GCJ02/WGS84；明确隔离演示模式保留独立路径 |
| 设备录像 | 未验收、离线不下发；重复点击只发送一次；提交人员和领用版本；换绑后旧响应不覆盖新状态 |

SSR 子组件替身不验证真实 `VideoFrame` 内部媒体播放、地图画布、浏览器权限和 CSS 布局。相关核心行为由下列单元测试验证，最终体验仍需浏览器/实机验收。

## 已有浏览器夹具

`tests/fixtures/` 中保留地图定位、分页和模态表单夹具，入口分别为 `map-location.html`、`pagination.html`、`modal.html`。`modal-runtime.js` 使用独立内存 store；这些夹具用于对应组件，不等于本次全部业务页已完成浏览器验收。

使用浏览器夹具时应采用明确隔离的开发配置与运行实例；不得把 fixture 的 mock runtime 别名合入正常前台构建，也不得让示例创建/绑定操作写入日常后端。本次未新增生产 seed、测试站点、账号或业务样本。

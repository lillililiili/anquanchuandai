| 编号 | 场景 | 预期 |
| --- | --- | --- |
| C1 | 仅领用安全带 | 不出现安全帽视频、抓拍、录像或镜头区；安全带语音如标待接入则禁用；双钩/SOS信息按能力显示 |
| C2 | 领用已验收安全帽且在线 | 视频区可用，显式点击后才请求开启；未验收语音/抓拍/录像仍禁用 |
| C3 | 安全帽离线或遥测过期 | 保留功能状态和明确原因；实时操作禁用，历史资料可查 |
| C4 | 没有领用设备 | 不提供当前人员实时设备操作；未领用设备事件仍可见 |
| C5 | 画面/请求中归还或换绑 | 原画面退出、旧请求不覆盖新人员；后端拒绝旧领用上下文；清理只针对原会话 |
| C6 | 两名观看者或跨页观看 | 一个观看者退出不结束另一观看者；最后退出释放原观看租约；轮询更新票据不周期性黑屏 |
| C7 | 无操作权限或切换厂站 | 实时操作禁用或被服务端拒绝；不能跨范围取得播放授权或设备控制 |
| C8 | 模拟手表显示关闭 | 人员、大屏和统计相应模拟体征消失；真实设备、历史业务数据不受损 |
| C9 | 未关联人员的设备告警/SOS | 显示设备号和未关联人员；接警/处置仍可用，不能自动领用到某个人 |
| C10 | 断网、超时、返回未知 | 保留待确认及原幂等键；不显示设备已接通、已停止、上传完成或外部同步成功 |
